# P4 · 汇总（方法论指令）

入口：仅经 P3 门进入（gate-exit:P3 在场；budget-exhausted 终态=mode=degraded 进本门降级流——账本质量不降，P5 首节强制披露未闭合格）。

## duty（命令序列）
1. 四校验命令先行：validate / verify-chain / hash-recheck / matrix-audit（「-」「!」标记格抽查+异常检测告警——批量置态与 fact 密度不符告警）。
2. finding 合并：supersede-finding（supersede+tombstone——旧证结论被新证取代时链式合并，不删行）。
3. POC 独立重放门（强制）：fresh 隔离子代理只拿 EV 卡片盲重放——驱动=tanyin-replay（机械判定三态：可复现/不可复现/环境差异），落账=set-replay-state 三态（VERIFIED/REPAIRED/REJECTED；环境差异=REPAIRED 候选，修复卡片环境前置条件后重放，max_retry=2）。无 matcher 的卡片=人工判定后落态。
4. 历史注记：批次 4 前该断言曾为 SKIP 并在报告披露；批4 起强制，披露义务仅适用于 REJECTED 未处置项的处置说明。
5. 攻击链落证（G-28，批5 T8）：tanyin-ledger graph-paths --from=<入口资产> --to=scope-root [--max-hops=6] → stdout 原样存 evidence/attack-paths.txt（只增不覆盖——重跑存 attack-paths-r2.txt 后缀）→ add-evidence --source-type=capture --artifact=evidence/attack-paths.txt --repro-command="<graph-paths 命令原文>" --raw-excerpt=<首条路径行>（content-hash 双指纹由命令自算=cli/ledger/norm.py artifact_hashes 单源，LLM 不手算；card_path 自动派生）。attack 链从「图推导」升格为「可审计证据」——repro_command=只读命令天然第三方可复现。

## entry 检查单
- gate-exit:P3 在场（converged 或 budget-exhausted 皆合法终态；degraded 态=P5 披露清单输入）
- verify-chain PASS（恢复协议兜底）

## exit 断言
- tanyin-phases gate --goal-dir <D> --phase P4 --timestamp <T>，断言五条：
  1. validate（13 表结构合法）
  2. verify-chain（链一致）
  3. hash-recheck（工件哈希复算一致）
  4. matrix-audit（抽查通过 且 无告警）
  5. replay-summary（无 REJECTED 未处置项）
  on_fail=halt：人工处置后原地重评。

## 回边
- P4→P4（back_edges）：重放=REPAIRED（修复 POC 卡片后重放），max_retry=2——重放修复循环不离开本门。
