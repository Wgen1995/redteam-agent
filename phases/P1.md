# P1 · 测绘（方法论指令）

入口：仅经 P0 门进入（gate-exit:P0 在场）。测绘不终于 P1——P3 全程可经 asset-added 事件续测（设计 §5.4 生长通路①）。

## duty（命令序列）
1. 侦察子代理派发（六要素委派单：目标/背景/边界/输出 schema/纪律/预算份额；子代理只产 submissions/<intent-id>/submission.json）。
2. 验收落账：add-asset（资产宇宙）+ add-fact（facts 即脱敏——子代理摘要行过 redact 才可回读上下文）。
3. 每资产 scope-check 内联判定：in_scope / out_of_scope / extrapolated（界外资产只记 fact 不 spawn 测绘）。
4. 资产树整合：add-edge --kind parent（父子层级；tree-check 完整性的前置）。

## entry 检查单
- gate-exit:P0 在场（verify-chain 跳门检测兜底）
- 授权窗口仍有效（goals.valid_from/until）

## exit 断言
- tanyin-phases gate --goal-dir <D> --phase P1 --timestamp <T>，断言三条：
  1. tree-check --complete parent（资产树完整无孤儿）
  2. scope-check --all-assets（全部资产已判定）
  3. validate（13 表结构合法）

## 回边
- 本门无事件回边；测绘生长不回 P1——新资产在 P3 经 asset-added 事件续测（recon intents 直达 pending+子矩阵初始化）。
