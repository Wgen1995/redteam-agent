# P2 · 规划（方法论指令）

入口：仅经 P1 门进入（gate-exit:P1 在场）。锚点冻结≠探索冻结——分母不动，新资产走子矩阵（设计 §4.10/§5.4）。

## duty（命令序列）
1. 读账本（goals.business_context + assets/facts 全景）+ 知识库指纹匹配（先例三元组内——批次 5 知识库，本批可空）。
2. matrix-init（列从 VOCAB WSTG v4.2 钉死；行=全部 in_scope 攻击面——分母法定）。
3. 分母就绪门（matrix freeze 前置步骤，见下节）：denominator-ready 退出码 0 才可冻结。
4. matrix-freeze（锚点冻结，不可重复冻结）。

## 分母就绪门（matrix freeze 前置步骤；探知项 G-14 追加件）
冻结前必须先跑：tanyin-phases denominator-ready --goal-dir <D>（口径=phases/PROTOCOL.md §4 冻结文本）。
- 只读账本（facts/assets/edges/intents），零落账。退出码：0=就绪 / 1=FAIL 清单 / 2=用法。
- 三断言：① 多源法定——每 in_scope 资产来源数≥2，或（unverified 标记+绑定该资产的在队列继续挖任务；界外资产不入本断言）；② A1-A8 类覆盖——每资产类非空，或「不适用理由」落账；③ 外推闭包——图谱无未处理悬空外推节点。
- FAIL 清单未清空（退出码 1）不得 freeze：逐项处置（补测绘 intents / 落不适用理由 / 处理外推节点）后复跑，直至 PASS 才执行 matrix-freeze。

## entry 检查单
- gate-exit:P1 在场（verify-chain 跳门检测兜底）
- matrix 未冻结（已冻结态的 already-frozen 幂等容忍见 PROTOCOL.md §1 判定表）

## exit 断言

  1. matrix-freeze（新鲜冻结；或 already-frozen 且 timeline 已有 matrix-freeze 事件的幂等容忍）
  2. matrix-gaps --baseline（基线行数>0 且 covered=true——覆盖全部 in_scope 攻击面）
