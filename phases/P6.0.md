# P6.0 · 清理门（方法论指令）

入口：仅经 P5.5 门进入（gate-exit:P5.5 在场）。一切外部副作用可逆性核销——不留后门、不留垃圾。

## duty（命令序列）
1. cleanup-checklist 从 timeline 提取全部外部副作用写操作（revert_cmd 非空行）。
2. 逆序执行 revert_cmd（后写的先撤；纯账本状态行无需回滚）。
3. 结果验证：每项核销复查无残留。
4. 全核销或人工豁免（豁免走 approve 落账 approvals）。
5. cleanup.md 清理声明附报告。

## entry 检查单
- gate-exit:P5.5 在场（verify-chain 跳门检测兜底）
- 签发版报告在位（清理声明附签署版）

## exit 断言
- tanyin-phases gate --goal-dir <D> --phase P6.0 --timestamp <T>，断言一条：
  1. cleanup-checklist --verify（全部 reverted 或 豁免行齐备）

## 回边
- 本门无事件回边；核销失败项=人工处置后原地重评（不进 P6）。
