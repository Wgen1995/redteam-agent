①外部侦察层 · 从域名到入口点清单

信息收集不是「扫完就完」，而是收敛为一张入口点底账；链路固定：资产→端口→入口→指纹→版本→CVE→验证

  • 子域收集：四来源（CT 证书透明/被动 DNS/暴力枚举/智能置换）+OneForAll/Amass；剔除泛解析噪声、看穿 CNAME 指向 CDN【核心】
  • 端口与服务指纹：懂 -sS SYN 半开与 -sT 差异、-sV 探针库机制；httpx 批量取 title/状态码/技术栈；filtered≠无服务【核心】
  • 目录爆破：判据链（状态码→长度→行数）；ffuf -ac 治「全 200」；高价值路径先手测（.git/.env/actuator/swagger）【核心】
  • JS 信息提取：gau 归档+LinkFinder 抽端点；grep AK/SK、内网测试接口、隐藏功能开关；source map 还原源码【重点】
  • 攻击面收敛+指纹→CVE：入口|参数|指纹|候选 CVE|验证状态一张表；Arjun 探隐藏参数；指纹≠版本≠可利用，逐条核对利用条件（如 Spring4Shell 需 JDK9+）【核心】

掌握标准：对任一授权目标跑完「子域→nmap→httpx→ffuf→JS 提取」产出入口点清单；复现「指纹→CVE→验证」闭环；爆破结果必人工复核——爆破器必误报，人工确认是纪律。

②Web 应用层 · 进得去、进得深、拿得稳

上册解决「进得去」（认证+注入），下册解决「进得深、拿得稳」（越权+逻辑+上传+反序列化）——越权与逻辑是审计经验迁移率最高的板块

  • 会话/JWT/OAuth：登出改密后旧 session 重放；JWT 缺陷五连（不验签名/alg=none/HS256 弱密钥/RS256→HS256 混淆/kid 注入）；授权码三依赖（redirect_uri 白名单/code 一次性/state 防 CSRF）【核心/进阶】
  • SQL 注入五通道（UNION/报错/布尔盲/时间盲/堆叠）+三库差异；手工五步定位回显位；sqlmap 指定通道+tamper 绕 WAF【核心】
  • 命令注入/XSS/SSTI/SSRF：分隔符语义与 OOB 带外验证；source→sink 分析；{{7*7}} 检测法；SSRF 协议进阶（gopher 打 Redis/dict 探端口）——外网打点进内网的第一跳【核心/重点】
  • 越权（水平/垂直/未授权）：IDOR 双账号对照+Intruder 批量；未授权四类（actuator/Swagger/管理后台弱口令/内存马视角）按「攻击者获得免鉴权高价值能力」定级【核心】
  • URL 鉴权绕过/逻辑漏洞/文件上传/反序列化：三层规范化差异生绕过（Shiro CVE-2020-1957）；支付状态机/验证码找回/竞态+HTTP/2 单包；五层校验绕过谱系；Fastjson @type 与 Shiro rememberMe【重点】

掌握标准：对任一 Web 目标按「认证→注入→越权→逻辑→上传」打出完整链，产出可复现 finding 卡（与⑥的 POC 卡规范衔接）。

③内网与域层 · 立足→隧道→凭据→提权→横向→域控

Web 打点给你一只 webshell，本层解决「之后怎么办」——主线六步固定，最后合规收尾

  • 域判断与本机收集：域成员三特征（机器账户/DNS 指向 DC/时间同步 ≤5min）纯命令验证；Windows 四问产出「本机档案」【核心】
  • 隧道与代理选型只看出网能力：TCP 自由→反向 SOCKS5（frp）；仅 HTTP→Neo-reGeOrg；不出网→netsh portproxy 逐层跳；nmap 必须 -sT -Pn -n【核心】
  • 凭据获取：SAM reg save+secretsdump；lsass minidump（转储前与客户书面约定）；DPAPI 连锁解密浏览器/RDP 凭据【核心】
  • 提权四主干：未加引号服务路径/UAC 绕过/令牌滥用（SeImpersonate→Potato 家族）/内核漏洞；Linux 先低噪声配置类后内核，对照 GTFOBins【核心】
  • Kerberos 与域控矩阵：认证四步一页讲透，所有域攻击都是对某一环打折；按「你有什么资本」选打法（普通域用户→Kerberoast/BloodHound；DA→DCSync）；痕迹处理只清自己新增的构件，删客户日志=销毁证据【重点/进阶】

掌握标准：打点后快速产出「本机档案」；GOAD 结业：独立画出完整路径图（打点机→凭据→横向→DA→DC）并逐节点标注事件 ID（4624/4768/4769/4104）。

④源码联动层 · 审计员优势的降维打法

核心心法：审计员最强的不是找洞，而是知道「这个洞对应的那个请求长什么样」——先构造假设，再验证

  • 入口点优先审计：先回答「哪些入口没被中间件挡住」再 grep sink；「路由清单×鉴权配置」表；认证≠授权，对象属主判断缺失即越权面【核心】
  • 代码→PoC 翻译三步：定位参数来源→按绑定规则构造请求→针对净化逻辑变形；判定信号按侵入度排序：响应异常→OOB→延时→回显，永远先低风险【核心】
  • 五个重点审计面：鉴权/越权、序列化、文件操作、SQL 拼接（MyBatis 美元大括号与 order by 位）、SOAP-RPC——看到特征就知道发什么请求【核心】
  • 半黑盒：发行包：「无源码」常是伪命题——官网历史安装包就是服务端真相快照；解包三必看（配置/依赖清单/凭据 grep）【重点】
  • 联动闭环「假设卡」：白盒假设→黑盒验证→证据留存三段缺一只是线索不是发现；仅代码推断未黑盒复现的永远标 probable【核心】

掌握标准：有源码时产出「路由×鉴权」表；看到 sink 能翻译成一条可复现请求；findings 目录换台机器隔一天 10 分钟内能复现——证据链合格线。

⑤客户端层 · EXE/APK 与协议

客户端是反哺三层的直通车：资产补充、老接口打点、内网横向线索

  • 前 30 分钟速查清单：识别→解包/脱壳→双编码 strings→分桶 grep→反编译只啃加密与网络两块→产出三件套（资产补充/疑似凭据/协议疑点）
  • 抓包与证书锁定绕过分三层：系统层（Android 7+ 只信系统 CA）→应用层 pinning（Frida hook 恒真）→双向 mTLS（.p12 常打包在 app 内）；分层排障别乱换脚本
  • 通信协议分析情报闭环：地址→抓包→帧结构（魔数+版本+长度+载荷）→回反编译源码对号→重放验证；Protobuf 用 protoc --decode_raw
  • 硬编码 finding 卡五要素：对象（组件+版本）/位置/值（脱敏+SHA-256）/验证/影响——缺一项评审会就被打回

掌握标准：任意 EXE/APK 跑完速查清单产出三件套；协议分析产出帧结构表，手工构造一条合法心跳帧收到预期响应即逆向闭环。

⑥交付层 · 报告、POC 卡、CVSS 与等保

报告是唯一交付物，客户「修不修、先修谁」只依赖它

  • 报告六节结构：概述（结论先行）→范围与方法→风险矩阵→漏洞明细（一洞一卡降序）→修复建议（P0-P3+责任方）→复测说明；交叉三查：概述数字=矩阵合计=明细条数【核心】
  • POC 卡片规范一条：拿到卡的工程师不咨询你、10 分钟内复现【核心】
  • CVSS 3.1：先影响（C/I/A）后可达性；躲开五个误评级（S:C 滥用/「注册就能打」是 PR:L/越权该 C:H/仅内网 AV:A/弱口令按凭据全夺评）【核心】
  • 证据留存与脱敏：成对留请求响应+SHA256SUMS；凭据不进报告；泄露类取样例前 5 条+总行数，禁止整表拖库进附件【核心】
  • 复测与回归：复测向后看旧漏洞、回归向前看改动面；四态判定（已修复/部分/未修复/风险接受——后者须客户书面确认）【重点】

掌握标准：一洞一卡，同事盲测 10-15 分钟复现成功且定级一致；交付前全文检索密码/Bearer/token/手机号正则无命中。

贰 · 工具链五组矩阵（toolchain.html 精华）

每个工具四问：做什么/一句话原理/陷阱；所有命令仅用于已签授权书（RoE）范围内的目标

侦察组 —— 黑盒第一步：攻击面在哪、门后是什么

  • nmap：SYN 半开扫描（只发握手前两步）；-sV 探针签名出版本。陷阱：只扫 TCP 漏 UDP（SNMP/NTP 在那）；无 sudo 时 -sS 静默降级更吵；客户环境 -T2~T3 --max-rate
  • httpx：大列表「谁活着/什么站/什么栈」快速过滤。陷阱：通配符 DNS 全解析同 IP 先 -ip 聚类；内网必须 -ports；大列表不配 -rate-limit 会打爆 WAF 留 429 污染客户日志
  • ffuf：FUZZ 占位替换+校准（先测软 404 基线，-ac 自动过滤）。陷阱：忘 -ac 满屏软 404 是新手第一大坑；递归指数级流量先 medium 后 large；定制字典＞通用
  • OneForAll+subfinder：多源聚合 vs 纯被动零发包——先被动后主动，被动零告警。陷阱：不配 API key 结果偏少；爆破类收集确认授权范围覆盖 DNS

Web 代理组 —— 看包改包重放的主战场

  • Burp Suite：127.0.0.1:8080 代理+动态 CA 证书 MITM 解密；Repeater 手工重放（80% 时间在这）。陷阱：系统全局代理劫持其他工具（FoxyProxy 分模式）；不设 Target scope 就开 Scanner 会扫到第三方（越界+浪费）；Intruder 忘 URL 编码选项破坏请求
  • mitmproxy：插件（addon）+事件钩子 request(flow)/response(flow) 批量改包；App/小程序抓包（mitm.it 装证书）。陷阱：Android 7+ 默认不信任用户证书需系统级（root）；脚本异常静默丢流量，前台跑盯 stderr

验证利用组 —— 疑点变可复现证据

  • sqlmap：五类判定通道按方言构造提数。陷阱：时间盲 SLEEP 拖垮小站连接池，生产必配 --delay 2 --threads 1 约时间窗；--dump 仅授权允许时用，合规做法 --schema/--count 级取证；不是发现器，先 Repeater 手工确认再交给它
  • nuclei：引擎与 YAML 模板分离，模板即代码可版本化。陷阱：matcher 只配 200 必误报至少双条件；模板库滞后新 CVE 自己写；主动/破坏类模板显式排除；结论措辞「覆盖范围内未发现」而非「安全」
  • fscan/vulmap：内网立足后第一轮广度扫描。铁律：授权书明确允许+约定时间窗+-nobr 起步（防锁域账号触发 SIEM 应急）；命中必须手工复核才进报告；边界外网段=越界红线

后渗透组 + 辅助组 —— 立足之后与交付的另一半

  • Metasploit：六类模块各有前置条件——先侦察后利用；NAT 后拿错 LHOST 回连必败（用 tun0/VPS）；EDR 常拦 meterpreter 降级普通 shell；横向移动要单独确认授权
  • CobaltStrike（只建概念与合规边界）：正版授权+客户书面授权（RoE 列明时间窗/目标/C2 域名）缺一即违法；网上「破解版」是供应链投毒重灾区（刑法 285/286 红线）；一人红队前期 MSF+frp 覆盖绝大多数场景
  • frp：反向隧道（frpc 主动连公网 frps）。陷阱：公网裸 frps 是扫描器重点（强 token+非默认端口+始终最新版防历史 RCE）；nmap 走 socks 只支持 -sT -Pn 别误判端口全关
  • 辅助三件：CyberChef（纯前端离线，敏感数据不出本机）；代码环境（venv 隔离+PoC 模板三件套：Session 复用/显式关闭校验注明原因/断言产出证据）；笔记与截图规范五条（全屏含地址栏/Burp 成对 Raw 视图/含完整命令/画面留系统时间/命名互引）

工具组合战术矩阵（七链路）+ 三决策要点

场景工具链输出物
外网资产测绘subfinder/OneForAll → httpx 存活指纹 → nmap -sV（真实 IP）存活资产表（url/title/技术栈/IP/端口）
Web 打点ffuf 目录+参数 → Burp Repeater 手工验证 → sqlmap -r 提数finding 卡+请求响应证据对
已知漏洞批量验证httpx → nuclei（高危过滤）→ 命中项手工复核高危漏洞清单（附模板依据）

三决策要点：①噪音控制——侦察信息增量>扫描流量增量，fscan 快全吵必 -nobr 起步，nuclei 显式排除 dos 类；②速率与时间窗——慢即是稳，生产一切速率参数显式声明，IPS 告警阈值写进 RoE；③授权边界——授权范围=工具能碰的最大边界，sqlmap 只对授权数据，C2 与 VPS IP 列入授权附录。

心法：每条链路的最后一站永远是「证据落盘」；先手工确认，再自动化放大；定制字典＞通用字典——工具只是把发现变成可交付输出的管道。

叁 · AI 渗透全景（ai-pentest.html 精华）

六大赛道+13 项目档案+十大架构模式——全部结论可回溯到源码级调研（星数与活跃度为 2026-09 核实值）

调研三结论（本节一切的出发点）

① 没有可以直接采用的完整体——13 个深度分析对象仅 nuclei 拿到 adopt-as-dependency（作依赖引入），其余 12 个全部 copy-pattern（抄模式不抄码），包括 64k★ 的 Strix 与 24.7k★ 的 PentAGI（平台形态深耦合，抽循环≈重写）。

② 赛道空白恰是机会——交战全生命周期状态契约、程序化 scope 执法、凭据占位符治理、认证后身份矩阵测试、中文合规报告、skill 评测体系，全行业（含商业 XBOW）缺位。

③ 供应链红线——国内工具（ARL/水泽/ENScan_GO）原仓库已删只剩来路不一的镜像；nuclei-templates 必须钉 commit+验签：持授权凭据的攻击路径上，任何依赖中毒=整场交战失陷。

赛道三 · 非 AI 自动化引擎

比 AI 渗透早十年、工程上最扎实：编排（DAG）、状态（工件缓存）、目录契约、资产图全在这里成熟

价值：交战目录契约的全部先例（Osmedeus workspace 契约、AutoRecon per-host 目录树、ARL 资产实体模型）。

赛道四 · 对抗模拟框架

给防御方验证检测覆盖——但十年前就解决了计划-执行-事实（fact 解析回填→变量消费）的状态机

赛道六 · 漏洞数据格式与报告标准

十大架构模式 P1-P10（入选标准=趋同演化：互不相关项目独立出现 ≥3 次）

P1 交战目录即状态契约

目录布局+固定契约文件是跨会话续跑的唯一载体。人工版：开工先建目录骨架，每条命令 tee 进 commands.log；死胡同也落盘。

P2 资产/事实中间层

recon 产物结构化为实体，「变量未填不动作」。人工版：一张 assets.csv 比十个原始输出文件值钱。

P3 确定性门禁在循环外

LLM 提议、代码裁决——依赖「模型这次会听话」的防线，安全水位等于最差的一次采样。人工版：范围校验做规范化后比对，双清单默认拒绝。

P4 验证后才算发现（证据收据制）

发现=声明+可复核证据收据；无收据最高只能算 lead。13 项目里 6 个独立演化出出卡质量门——趋同最强的一条。

P5 POC 即数据

声明式卡片与执行器分离。人工版：每个 POC 改写成「请求原文+预期判定」两段式，可复现可进复测清单。

P6 报告从结构化存储确定性重建

存储是唯一真相，报告是纯函数投影。人工版：报告素材从交战第一天结构化积累——报告期是聚合排版，3 天缩到 3 小时。

P7 工件即缓存幂等续跑

产物存在性=完成断言；「进度」和「产出」是两回事。人工版：长扫描都带 -oA 落盘，重跑前先 ls。

P8 预算限流树（展望）

token/请求/费用分级预算与速率硬帽。人工版：给每天定「请求预算」，超了就收工复盘。

P9 覆盖负空间台账（展望）

记录「该测未测」的负空间。人工版：一张「没测什么+为什么」表进报告，防覆盖幻觉。

P10 凭据占位符网关（展望）

凭据真值只在注入瞬间出现。人工版：报告中一律用已脱敏占位，原件加密另交。

配套 8 条反模式（每条有实测出处）：提示词级 scope 必被绕过/fail-open 默认放行/凭据明文进 prompt 日志/全内存状态非优雅退出即丢/安装即 YOLO 全 allow/README 宣称与实现不符/护栏只堵单出口/resume 只记进度不记产出。

协作位与四防陷阱

AI 的定位：知识渊博、反应极快、但会自信编造且不能替你担责的远程同事——AI 消灭的是杂活（chores），不是能力（competence），更不是责任。判据一句话：「把这件事交给 AI 三个月，你的验收标准还能过吗」。

四防陷阱：①幻觉战果（AI 说打下来了——查证据收据，没有就不算）；②越界风险（AI 不理解法律边界——scope 机器执法，不靠自觉）；③凭据泄漏（prompt/日志是泄漏高发面——占位符+终检）；④供应链投毒（依赖中毒=整场交战失陷——钉 commit+验签）。每类都有实测样本与架构级反制。
