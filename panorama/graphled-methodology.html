交战思维 · 一仗怎么打（横向流程）

从授权到报告的六步，每步都标了「执法件」——就是那一步管住它不许乱来的机器（宪法 #41 人话：执法件=不用人盯、违规自动拒的关卡）。九道门全程护航，门序单源自代码 core.GATE_ORDER，界面词表一字不差。

六步横向流程

① 八问授权

门 P0 授权确认

建任务先答八问：授权件（原件+sha256+签署方）/窗口期/范围白名单/紧急联系人/预算/凭据来源/强度档/法律条款。

执法件：缺一=422 整单拒（server.py:316 八问校验）；授权四件落 goals.tsv；范围落 scope.tsv；凭据真值永不进账本（vault 占位符）。

➜

② 意图链

门 P1 范围检查 · P2 预算

任务拆成一条条意图（intents.tsv），战士领取打租约（时限标记），超时自动回收重授；无可用引擎=blocked 留因，不静默丢。

执法件：双抢互斥 REJECT；租约超时先落 blocked[lease-expired] 回收行再重授（W2 租约舰）；预算三维（token/请求/时长[$]）触帽=优雅停+收尾令。

➜

③ 战士执行

门 P3 执行

自研 AI 大脑循环：领意图→组上下文（50 张技法卡按意图检索注入+上轮自纠信号）→选模型道→发 JSON 指令→调工具→写账。

执法件：每条工具命令过守卫门链（黑名单/范围界外/限速/审批档）；资源三帽（CPU/进程/内存）；心跳+停滞自杀重生交租约；断点续跑按 timeline 末行重建。

➜

④ 机械重放验证

门 P4（发现入卷硬门）

每个发现由独立进程原样重放（tanyin-replay，上限 3 次）；重放不过=不算漏洞。

执法件：未验证不入卷——SARIF 只收已验证（report_artifacts.py）；验证状态三态=已验证/待验证/已失效（事件溯源最新）；误报防线核心=机器复算，非人肉双签（#17 修订 C 用户裁定）。

➜

⑤ 复测

门 P5 复测

对「已修复」候选自动排队复测；复测页已建成待挂载。

执法件：复测走 rerun 门（gate reset 重走门序）；账本 supersede 墓碑——翻案留全史，后代行胜。

➜

⑥ 报告签发

门 P5.5 报告→签发 · P6 清理 · P6.0 沉淀

报告中心：六节预览、渲染输入哈希钉（同输入同输出）、版本链、签发位（草稿→待签发→已签发锁定）。

执法件：渲染纯函数两跑哈希比对；pass.json 绑定逐件复检，篡改=红条不回退；战毕过清理门（P6）清痕——仓净 0 行/容器 0 残留为验收。

九道门（门序单源=core.GATE_ORDER，界面词表同款）

P0 授权确认P1 范围检查P2 预算P3 执行P4 复测前的发现验证P5 复测P5.5 报告P6 签发P6.0 清理→沉淀

词表实读自 cli/webui/console.py（_PHASE_LABELS 与 core.GATE_ORDER 强校验，失配即崩——防两份词表漂移）；门文件=phases/P0.md..P6.0.md。界面叫「阶段」，代码里叫「门」，一回事。

三条全程律（哪一步都在管）

范围执法：四层拦截（账本/执行通道/宿主 hook/出口代理）+scope 四 kind 匹配+deny-list 黑名单单源；范围外发现走分域异步扩展审批（宪法 #45：门按域分不整体停），全停仅限法务红线（窗口到期/急停/预算硬顶）。

预算执法：token/请求/时长（美元）三维预算树；超限=BUDGET-ENFORCE 收尾令重启（HANDOFF F3）；预算触帽时间窗优雅停。

留痕执法：每一步（含拒绝本身）写 timeline.tsv 哈希链行——任意历史时刻可回放（演变回放条：帧号=记录行号）、可第三方验真（verify-chain）。

为什么这样设计（三句）

  1. 误报是生死线（宪法 #43）：所以验证不是「模型说算」而是机械重放——机器复算才算数。
  2. 授权是地基：八问缺一不开仗，凭据真值永不进账本——安全产品自己先不能成为泄露源。
  3. 越打越强要能证明：打法沉淀成 50 张技法卡按意图注入，评测棘轮管能力回归——这套循环的目标是把「经验」变成「资产」。
