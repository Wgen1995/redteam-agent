一、三个入口：同一个战士，三种监督模式

门A/门B 打真实目标；门C 只打靶场。门里干活的是同一个 AI 战士+同一套账本纪律，唯一区别是「监督员是谁」。

门A · 直接对话 opencode ✅Claude Code 🔮codex 🟡

  • 您在聊天窗口说「用 tanyin 技能，对 X 开战，授权书在 Y」
  • AI 反问授权八问 → 您逐条答 → 开打
  • 战中您可随时插话指挥、看它现场操作
监督员=您本人：它停了您点「继续」，它问您答

门B · 引擎托管 tanyin-runner ✅

  • 一条命令 → 走人（真实项目/过夜跑推荐）
  • runner 替您值班：盯心跳 / 它停了替您点继续 / 断网拉起 / 假完成不认
  • 战例：b24 断网击杀+三度点火零账损；b25 restarts=0 跑完
监督员=Python 看门狗（详见第三节）

门C · 靶场练兵 battle.py ✅

  • init / launch / watch / settle 四条命令开一场训练战
  • 战毕自动评分（56 分母）+ 金样钉测防退化
  • 四战成绩：0.70（单样本峰值）/ 0.66（稳定最优）/ 0.62 / 0.57
监督员=看门狗+评分器（全自动化程度最高）

二、五层结构总图（从外到内）

战术归 AI、判据归账本、保活归 Python——三层互不越权；外面再包分发与度量。

① 看门狗层 · tanyin-runner ✅（b10 四件套已上）保活 · 判完成 · 救故障——完全不碰战术。心跳 30s ✅ / 停滞击杀 8min ✅ / 断点续跑 ✅ / 完成判据=gate-exit:P4（不认进程退出码）✅ / 分级击杀（SOFTSTALL 观察）✅b10 / 重启指数退避 ✅b10 / 战中指令注入 ✅b10 / 自适应监听 ✅b10
② 判据层 · 账本法 ✅44 条 CLI 命令 · 哈希链防篡改 · 状态在盘（重启不丢）——管「跑得好不好」：真伪、清帐、覆盖、收敛。八表+九门细目见第四节
③ AI 指挥层 · 技能战士 ✅管「下一步打什么」，全权。SKILL.md 总控路由器 / phases 各门详令 / dict v3.14 漏洞字典 / BRIEF 30 面战书（0.66 的来源）/ 侦察+重放子代理
④ 度量与飞轮层 ✅管「越改越强不退化」。评分器键控 v7 / 金样 G-r4→G-r26 钉测 / 套件 RC=0 / 复盘 RT-0001→0023（两条落律·一条对照实验裁决回滚）

四、判据层细目：八表 + 证据体系 + 九门
