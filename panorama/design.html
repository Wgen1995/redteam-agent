是什么：一句话愿景＋四支柱

一句话愿景

把已实战验证的渗透方法论（CNPEN 82 漏洞）固化为纯 SKILL 套件，装进任意编码 agent 即可按纪律执行全类型渗透：图谱账本驱动测试演进（图谱收敛＝测试完成），引擎契约编排异构引擎，知识库跨会话复利。

四支柱：复杂性分别放在哪里
  • Graph 图谱工程——放在「状态」里：世界建模为显式节点与关系，推理变成可执行的图查询；状态外置、结构化、可检验
  • Loop 循环工程——放在「过程」里：感知→决策→行动→落账闭环持续演进，计划是活的；终止条件可计算，配预算控制
  • Harness 脚手架工程——放在「基础设施」里且尽量用现成的：不重写 agent 运行时，与宿主／引擎的耦合收敛为契约
  • Context 上下文工程——放在「上下文生命周期」里：什么常驻、什么按需、何时压缩、何时重启——上下文是被设计出来的
