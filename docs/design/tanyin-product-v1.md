# 探隐产品定义 v1（2026-10-15 用户批准版）

> 本档取代此前的定位摇摆，为一切后续批次的最高依据。法律条款（五律/语言律/沟通律）见 tanyin-target-form.md，继续有效。

## 定位（用户原话裁决）
**最大目标 = AI 自动化渗透。** 探隐 = 部署在自有电脑上的 AI 自动化渗透平台： 授权目标进，AI 战士自主打，程序执法记账验证度量，人只做介入/放行/决策。审计不是产品身份，是自主性的地基（自主决定能打多快，账本决定敢让它打多快）。

## 生态位（钉死）
- 自持编排器: Python 3.9 纯 stdlib 单进程，自己就是生态中心
- 大模型: 双车道直连 API——①判据/规划者 judge_client+llmpool（已建）②战士群视 Tier2 闸门实验决定是否吸收
- 战士: opencode 现役（13 战基线）; 不做任何 harness 插件（0.91）; 不用任何框架
- 互通: ZhuLong findings 导出（/api/imports）; 任意 harness 薄桥遥控

## 产品形态（D4）
部署(clone 即用零依赖)→启动(tanyin serve 单命令)→登录(操作员口令)→全程浏览器（建项目向导/开战按钮/看盘/介入/审批/报告下载）。CLI 退居引擎层。

## 路线（D1/D2/D3）
v0.9d 界面大改（皮肤 ZhulongFire+八视图+人话律+会话页只读+ZhuLong 互通）→ v1.0a 双图一桥（资产图程序挂载+锚点覆盖，白盒引擎并入当解析前端）→ v1.0b 常驻循环（规划者直连 API+多战士+登录多战场+项目向导+Tier2 闸门实验）→ v1.0c 控制面（介入框+审批卡+报告页）。

## 界面基线
八视图: 战局总览(重做)/活动流/会话(新)/热图/十边图/证据卡/度量/实验。皮肤=ZhulongFire（#2563EB/一屏式/深浅双主题/动效≤3）。偷单 40+ 条见 docs/research/liveui/ 各报告。

## 修正案 A · 白盒引擎设计（2026-10-15 用户共创定稿，v1.0a）
双车道:
- 车道A 确定性解析器（零 LLM）: OpenAPI/Swagger→endpoints/params/auth; 安装包(zip/tar/jar/apk)解包→清单文件→资产; 源码 pattern 扫描（路由/硬编码密钥/危险 sink，借鉴 GenSift .pattern 文件）。产出全部带出处（文件:行）经锚点挂资产图。
- 车道B LLM 深度审计（吸收 GenSift——用户自己的资产 Wgen1995/GenSift,本地 ~/.claude/skills/gensift）: sink 卡逐卡五步证伪+盲验证,作为规划者按需调用的深度车道; 卡片结论回写证据卡走探隐 replay 验证。覆盖不可谈判律继承（所有 endpoint/sink 入矩阵,不可抽样）。
- 运行契约=用户四原则（提交即返回/领取不等待/超时显式化/账本两相性）。

## 修正案 B · 语言性能决策（Python vs Go,2026-10-15）
**留 Python（置信 85%）**。依据: 实测瓶颈=LLM API 延迟(秒级)>>>本地 CPU; 单操作员规模; 解析热点 Python 正则底层 C 速度+multiprocessing 可救。
**Go 边车触发器**（任一触发→仅热点件做 Go 隔离二进制,账本链留 Python 不重写）:
①典型仓库白盒解析实测>10min 且分块/多进程救不了 ②并发战士>50 或多租户 ③客户机无 python 的分发硬需求。

## 修正案 C · 共创模式（用户令）
用户随时补充内容（需求/方向/参照物/自己的资产如 GenSift）——每条当日落入 spec 修正案或 HANDOFF,绝不丢失; 参照物分析统一入 docs/research/liveui/ 编号续延。

## 修正案 D · 源码定位裁决（2026-10-15 用户共创，E6 评审日补落档）
**架构=B（渗透内环）+审计模式开关**: 源码是渗透循环的情报车道,不设独立环节。车道A 解析即时入图;车道B 深读逐卡证伪被规划者调度,但**覆盖不可谈判律继承**——每卡终态必达（已分析/延后带理由/超范围作废）,engine deferred=0 进 P4 收口判据（E6 裁决④）。同一引擎 battle/audit 双模式（scope=仓库/egress 全封/零网络,出口换审计专报）。度量: 源码车道贡献单独计数,McNemar 判增益（实验设计按 E4 修正: 战层配对置换 N≥4+GT-free 工作区+treatment_artifact 三 sha256）。翻案条件: 纯代码审计合同占比>30% 则审计模式升格一级入口。
