# GraphLed 架构文档 v1(2026-10-18;基础=五舰对齐+九舰评审+W1 战果)

## 1. 系统形态: 一核多壳
核 = 账本+执法(真相与纪律)。壳 = 浏览器控制台 / 终端 CLI / 宿主对话(门A) / 被驱动面(multica JSONL,W7) / MCP 服务器(W7) / 远程节点(W7)。所有壳走同一写路径(CLI 子进程/协议), 零直写。

## 2. 六层架构
1. **界面层**: Vue3 控制台 21+ 页(dist 入库保 clone 即用); 读面全过登录门(W1 已落)
2. **终端层**: 49 命令(--json/退出码 rc0/1/2/3)+battle auto 一键链(W1 已落)+watch 全屏工作台(W6)
3. **执法层**: 四层 scope/canary/OOB/副作用黑名单 fail-closed/setrlimit 资源护栏(W2)/审批卡+P5.5/清理门
4. **账本层**: 13 表 TSV 哈希链(真相源)+SQLite 加速层; O(1) 追加(W2a); 图谱=账本投影(11 类节点, 演变回放条)
5. **引擎层**: 插槽制(nuclei 在役/VulnClaw 已接线 494 行)/白盒双车道(W4)/工具卡 25+15 张(W3)/C2-lite 账本化(W3)
6. **模型层**: 双模接入(宿主通道+llmpool 网关,W5 接线)/档位=插槽参数/成本=网关侧 usage 外挂

## 3. 数据架构
- 13 表清单与哈希链机制; 单源口径: 命令=registry(49), 表=schemas.json(13)
- 图谱 11 类节点(起点/目标/意图/事实/漏洞/提示/压缩/派生/意图链/产出/证明)冻结进 contracts(W6)
- 备份=目录即交付物; 升级=重放重建(W2/P1)

## 4. 语言策略
核(账本/执法/CLI/引擎)=Python3.9 纯标准库(零依赖律)。热部件按实测换: Go 边车(高并发调度触发)/Rust(终端 UI 参考 VulnClaw)。规则: 哪个部件慢哪个换, 核永不换。

## 5. 界面信息架构(21+ 页, 菜单级)
- 作战组: 登录/开战八问/总览/战况/图谱(演变回放)/发现库三态
- 管控组: 审批中心/命令审计/拦截规则/急停/通知收件箱
- 资产组: 资产+DSL 搜索/工作区/跨战资产登记
- 系统组: 模型池/战士配置/工具卡注册表/技法库/设置/日志 SSE/用户角色
- 演示组: 验真三步/demo 开箱
- 每页配 CLI 对等件(双面律)

## 6. 模型接入图(双模)
战士(宿主会话, 默认) ⇄ llmpool(自建网关: key 池/轮询/计量, W5) ⇄ API(bigmodel 等); 引擎插槽(整引擎可换); 成本走网关 usage 外挂不采信内建。

## 7. 扩展面
- MCP 双向(W7 必做): client 接生态+server 暴露账本/执法/图谱(五家只做消费者)
- 被驱动面(W7): graphled --stdio JSONL v1(multica 17+ 运行时翻面为分发渠道)
- 远程节点(W7 G9): 令牌绑授权书(吸收 ZhuLong 被假 runner 注册教训)

## 8. 波次映射
W1✅(授权真化/读面门/一键链/插槽/定名)→W2 在航(地基/单源/CI/租约/serve)→W3 肌肉(工具卡+C2+利用深挖)→W4 白盒→W5 大脑+模型接线→W6 界面超越→W7 企业门禁+扩展面→W8 价值呈递。总量 53-65k 行, AI 周计。

## 数据架构·O7 决断(2026-10-18 用户质询性能后拍板)
- SQLite 投影层升格必做: schema+确定性重建(坏了就删从账本重建)+资产/覆盖/发现查询读路径迁移(~700行)+性能回归钉(追加3400行/s基准,查询阈值)
- 负载依据: 单仗1847行/全链2M行(千仗级),追加实测3400行/s,单仗单写者按目录横向摊开
- 天花板诚实: 上千人同写同一仗才触顶——非本业务形态;触顶日=投影层换读写分离,真相层不动
