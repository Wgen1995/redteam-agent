📈 知识飞轮与召回率 · L1 知识体系 · 越用越强的机制与度量

「不断增强」不是口号，是四条具体机制 + 三层度量。治理加固：ingest 走 staging 审批门、脱敏反向验证、先例绑定客户三元组（三元组=「哪个客户+哪个授权资产+哪次授权时间窗」，三字段全同才可复用——跨客户复用=拿 A 的授权打 B，越权事故；窗口过期先例自动失效）、词表 WSTG 基线多元化。攻击知识有复利也有衰减——知识库「越用越准」而非「越用越臃肿」。

知识库结构（knowledge/ · 治理）

precedents/先例库（脱敏实战链路+命令模式+客户三元组绑定——三元组=「哪个客户+哪个授权资产+哪次授权时间窗」，三字段全同才可复用：跨客户复用=拿 A 的授权打 B，越权事故；窗口过期先例自动失效）P3 先例注入 + 安全先例机制——禁止跨客户匹配

四条复利机制（加固）

① ingest 摄入 「用探隐摄入 <路径>」：任意文档 → raw/ → 自动提炼 → staging/ 暂存 → lint 报告+用户审批 → 入正式区。初始知识库 = CNPEN 82 漏洞（走同一审批门）+ nuclei 模板库 + PortSwigger WSA 分类——词表基线多元化，防单源过拟合。
② P6 脱敏沉淀 session 结束：脱敏提取（域名/IP/凭据→占位符）→ 反向验证（session 内出现过的域名/IP/凭据/token 在草稿中零命中才放行） → journal 草稿 → 用户审批（落 approvals 表）→ 写入。实体页自动累积更新。
③ 进化门槛（learned→core）复现≥2 次 + 跨目标有效（实体页数据判定）+ 人工审批 + 无目标指纹泄漏（反向验证）。四条全过才晋升。防一次性巧合污染核心库。
④ lint 保鲜 每 pattern 带 last_verified；session 开始 lint 报告陈旧模式；新 session 反证自动标记矛盾 → learned 降级队列——降级需 N≥2 次独立反证，且区分「防护拦截」与「代码修复」（依赖差分证据 pair_group）。攻击知识有衰减机制。
设计思想：知识复利的关键不是「存得多」而是「信得过」——staging 审批门（ingest 与 P6 对称，防投毒）+ 进化门槛（多次验证才转正）+ 保鲜机制（过期自动降级）+ 反向验证（防跨客户泄漏）四道闸，让知识库随使用越来越准。来源：llm-wiki-agent + GenCPT + dsh-reverse-skill + 审计加固。

召回率度量框架（从「看运气」到「可度量」· 四层）

① 矩阵层 — 覆盖完整性攻击面×漏洞类型矩阵，五态标记，终态门禁：空格必须消灭。列从 VOCAB.md（WSTG v4.2 全集基线）钉死并版本化——矩阵列集合的召回=总召回天花板，不能源自单一项目样本；"-"/"!" 格进 P4 抽查防廉价闭合。
② 图谱层 — 探索完整性收敛条件可计算：无未消费 fact ∧ 无 pending/active intent ∧ candidate 池空 ∧ 矩阵无空格。何时停止=数据判定，非主观感觉。
③ 知识层 — 复利度量先例命中率 / 新模式晋升率（learned→core）/ 同类型目标对比（空格↓ 收敛轮数↓）——知识库质量的直接指标。
④ 靶场层 — 检出率 靶场种 20 个已知漏洞测检出率——过程完整性之外唯一的诚实召回数字。三层框架度量的是过程，这层度量的是结果。
诚实边界：探隐不承诺「找到全部漏洞」（渗透测试本质是抽样），承诺的是覆盖可度量（每格有判定，词表 WSTG 基线防单源过拟合）+ 复利（同类型目标越测越全）+ 可回归（负结果入账，修复验证有基线）+ 可检验（靶场检出率）。

Loop 演进对召回率的提升路径

阶段召回来源机制
第 1 次测目标类型 A矩阵基线 + 通用模式知识库冷启动（CNPEN 82 漏洞 + nuclei 模板 + WSA 分类 ingest 后已有厚底子）
第 N 次测目标类型 A+ 先例库（A 类已知模式全注入，客户三元组内匹配）
+ 实体页（组件级模式，跨目标验证过）
+ 失效模式排除（省 token 花在新攻击面）		P2 指纹匹配注入 + P3 先例注入 + lint 保鲜排除
度量方式同类型目标 session 对比先例命中率↑ · 矩阵空格↓ · 收敛轮数↓
原理逻辑：召回率提升的来源不是「模型变聪明」而是「知识库变厚且变准」——每次测试都在为同类型目标积累先例，且失效模式被自动排除（不浪费预算在已知无效路径上）。
与工程范式的关系：知识飞轮是 Loop 范式在跨 session 尺度上的延伸——单 session 内循环到图谱收敛，跨 session 循环到知识复利。Graph（graph.ndjson 全局关联）与 Harness（纯 markdown 知识页，任何宿主可读）为它提供载体；staging 审批门是安全纪律在知识层的延伸（守门能力贯穿测试与知识两个环节）。
