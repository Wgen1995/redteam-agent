四支柱不是功能模块，而是四种回答「agent 的复杂性应该放在哪里」的立场：Graph 放状态、Loop 放过程、Harness 放基础设施、Context 放上下文生命周期（补立——原设计最弱处恰是三大哲学里没有名字的那一个）。每节六段深析：哲学立场→解决什么→架构原理→业界谱系→代价边界→探隐选型。
