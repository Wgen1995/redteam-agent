# report-summary baseline 版本兼容规则与趋势对比降级

> 本文件为 `skills/report-summary/SKILL.md` 步骤 1 的 baseline 兼容性参考。核心工作流见 SKILL.md。

---

## baseline 版本兼容性检查

读取 baseline 报告时，检查其 `suite_version` 字段：

### 版本一致（如 V3 vs V3）

- 正常对比，包含：
  - 合规覆盖率对比
  - 攻击确认对比
  - 新增/修复项对比

### 版本不一致（如 V1 vs V3）

- **降级为简单趋势对比**：
  - 只对比漏洞数量趋势
  - 只对比合规 pass/fail 数量变化
  - 不做细节归一
- **在报告开头标注**：`⚠️ baseline 版本不一致（baseline={旧版本}, 当前=V3），仅做趋势对比`

### baseline 永不替代当前测试

无论版本是否一致，当前测试结果始终是权威结果。baseline 只用于 delta 报告对比。

---

## 趋势对比降级规则

当 baseline 版本不一致时，趋势对比限于以下维度：

| 对比维度 | 版本一致时 | 版本不一致时 |
|---------|-----------|------------|
| 合规覆盖率 | 逐规则对比 pass/fail 变化 | 只对比总 pass/fail 数量变化 |
| 攻击确认 | 逐 ATK-CAND 对比状态变化 | 只对比 C1/C2/C3 总数变化 |
| 新增/修复项 | 逐项列出新增违规和已修复项 | 只对比违规总数增减 |
| 评分对比 | 各维度评分同比 | 只对比综合评分同比 |
