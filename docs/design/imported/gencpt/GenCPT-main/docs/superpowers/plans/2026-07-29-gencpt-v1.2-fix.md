> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 修复 GenCPT V1.1 的 39 个问题，让实现兑现设计哲学的承诺

**架构：** 分层修复 5 组——编排层（入口 SKILL 门控）→校验层（QA 量化门控+字段校验）→图谱层（KG 自洽性+强制补采）→Phase 层（ARE 对抗+可视化增强）→SKILL 拆分（>400 行拆分为 references/）

**验证方式：** 连接 k3s_server 实际运行 GenCPT full 模式，对比修复前后产出
