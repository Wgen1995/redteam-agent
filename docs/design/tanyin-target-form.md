# 探隐目标形态 spec · 「武器-观察-控制-引擎」四面一体（2026-10-11 批准）

> 决策链：ARTEX 五路深读(docs/research/artex-deep-dive/0-index.md) → DSH 二开评估(否,仅遥控器) → API 直连分析(窄调用是/全自持挂触发器) → 形态呈批 → 语言呈批 → 本 spec。批准人：用户。

## 0. 判据（形态为谁服务）
① 持牌实战（单人，武器零依赖随身）② 指挥与审计（实时看战局/事后对账/演示）③ 工程演进（改系统要快）。
任何形态伤害①是错的；②是当前最大缺口；③是既有优势不可丢。

## 1. 四面一体目标架构

- **观察面 tanyin-web（v0.9 · 只读投影）**：stdlib http.server + SSE（timeline 追尾）+ 纯静态 HTML/SVG。视图： 战局总览(phases+budget+活动流)/战斗列表(进度+战士态+b10 通道)/资产覆盖热图(matrix 消格)/十种边血缘图(viz_render 升 SVG)/发现+证据卡(E-index 重放三态)/度量页(12 战召回曲线+McNemar+双臂——ARTEX 没有的招牌页)/审批回放(ask+approvals+P5.5)。
- **武器面（现脊柱，形态永不改）**：战士(opencode 可换宿主)+13 账+哈希链+九门+battle 度量。
- **控制面（v0.9.5 · 薄，默认不建，单独审批后建）**：ask/审批卡片+battle 按钮+b10 指令发送。法律：UI 是 CLI 的客户端，永不做第二个写入者。
- **引擎面（渐进自持 · 直连 API）**：judge 窄调用(v0.8)→fusion 引擎循环长大→按触发器吸收战士职责；不做大爆炸重写。
- （可选）DSH 薄桥插件：驾驶舱遥控器，非底盘。

## 2. 五条形态法
零依赖律（武器）· 投影律（观察面只读）· 单写入路径律（控制面只能走 CLI 门）· 渐进自持律（引擎按触发器生长）· 可换宿主律（战士）。

## 3. 语言律（同日批准，与形态法同级）
- 服务端（全部四面）：**Python 3.9+ 纯标准库，永久**。
- 前端（观察/控制页面）：**HTML+CSS+SVG+原生 JS，零框架零构建零 node**（跑在浏览器，不进部署目标运行时，不破部署律）。

### 编码法（CI 可检）
1. 服务端 import 只来自 stdlib——加 CI 自检。
2. 前端禁 npm/禁构建产物入库/禁 CDN 引用（离线可用律）。
3. 3.9 兼容：禁 match 语句/| 类型别名等 3.10+ 语法。
4. 新模块落盘前过 py_compile+全量测试（既有律）。

### 排除项与重审触发器
| 排除 | 理由 | 重审触发 |
|---|---|---|
| Go | 重写=基线作废；单操作员无 goroutine 需求 | SSE>100 连接或队友级多用户 |
| Node/TS/Next | 双破零依赖+零构建 | 单页原生 JS>2000 行 |
| Rust 等 | 同 Go+战士读写摩擦 | 不设 |
| Python 基线上移 | 3.9=macOS CLT 事实 | 公司统一 Python |

### 语言可证伪触发器
- 观察面单机 SSE 实测撑不住且 asyncio 重写无效 → 仅观察面允许多进程/线程方案（仍 stdlib）。
- 前端任何单页 JS>2000 行 → 允许单一无构建轻库（htmx 级），仍禁构建链。
- 触发器外，语言法五年不变。

## 4. 建成顺序（每步独立可停）
1. v0.8 借脑三件套+judge 窄调用（已呈批，与本 spec 并行）
2. v0.9a 观察面骨架：server+SSE+战局总览/timeline 流（含 stdlib SSE 稳定性验证——风险①）
3. v0.9b 覆盖热图+十边图+证据卡页

6. DSH 薄桥（可选）

## 5. 风险与默认（诚实申报）
- 风险①： stdlib http.server 长连接 SSE 稳定性未实测——v0.9a 首批即验证，不行换 asyncio（仍零依赖）。
- 风险②： 控制面再薄也是攻击面——默认只读，控制面单独审批后才建。
- 默认单用户设计；多用户（鉴权/并发写）需要时另立 spec 重审（含 Go 重审触发）。

## 6. 关联决策存档
