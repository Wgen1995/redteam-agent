# 探隐 UI 设计 v1（2026-10-15 定稿，v0.9d 执行）

## 骨架（行业共识+ARTEX 实证）
左侧栏（三分组: 看战况[总览/会话/热图/十边/证据]/看战果[度量/实验]/管战场[设置→v1.0b 新建项目]）+ 顶栏（战局切换器/通知/明暗主题切换）+ 内容区。
wireframe 见 HANDOFF 2026-10-15 行（ASCII）。

## 令牌（ZhulongFire×ARTEX 实证融合）
- 灰阶 12 级结构（借 ARTEX 层次,数值 ZhulongFire 调）; 品牌蓝 #2563EB; 圆角 8px; 明暗双主题 CSS 变量镜像; 动效全站≤3（pulse/spin/骨架屏）。
- 状态色: 语义徽章 rgba(色,0.1) 底+实色字（CSAI 配方）。

## 每页布局
- 总览: 战斗卡+九门进度 / 活动流直播(SSE) / 最新发现列表(点击跳证据卡) / 预算条(≥80%红)。
- 其余七页沿用现结构换壳; 会话页=对话流+工具卡折叠(details/summary)。
## 人话律
每页中文标题+「你在看什么」副题; 黑话清零。
