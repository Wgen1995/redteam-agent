|---|---|---|---|
| 怎么进 | 聊天窗口一句话 | 一条命令后走人 | battle.py 四命令 |

## 四、判据层细目：八表 + 证据体系 + 九门

账本=唯一真源。表按生命周期分三组；证据体系独立成卡；**九门是唯一合法流程，过门只能靠 gate 命令（带前置校验，嘴说无效）。**

### 八表（三组）

| 分组 | 表 | 管什么 |
|---|---|---|
| 战前四表 | goals.tsv | 目标（一任务一行） |
| | scope.tsv | 授权范围（include/exclude/oob） |
| | creds.tsv | 凭据（预发账密等） |
| | approvals.tsv | 审批记录（P5.5 签发落此） |
| 作战四表 | assets.tsv | 资产（服务/端点/IP/域名） |
| | facts.tsv | 事实（要么被消费要么显式弃+理由） |
| | intents.tsv | 意图（要么验证要么 blocked，不许蒸发） |
| | findings.tsv | 发现（一洞一行，可被 supersede） |
| 判据三表 | timeline.tsv | 审计链（哈希链防篡改，心跳落此） |
| | edges.tsv | 关系边（supersedes/cross_ref 等十种） |
| | matrix.tsv | 覆盖矩阵（空格必须消灭或披露） |

**证据体系**：E-index.tsv + evidence/ 可重放证据卡（原始请求响应+信标词）。
**计分铁律（精度门）**：发现计分四条件=状态 active + 端点与资产对得上 + 证据卡重放已验证 + 信标词在卡——**烂帐=0 分**（b25 的 54 发现只计 32 即此律）。
