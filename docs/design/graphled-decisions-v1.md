# GraphLed 四项设计决断(2026-10-18,按超越律默认超越版;用户可否决单条)

| 题 | 决断 | 理由 |
|---|---|---|
| Q1 模型接入 | **双模**: 默认宿主通道起跑, llmpool 自建网关并行接线(W5), 插槽制保证随时换 | 不绑死任何一方; flash/4.7 对照已证插槽价值 |
| Q2 部署节奏 | **单机先深后宽**: 单机单人打穿全流程→W7 三角色→多租户 ADR 后议 | 账本纪律先立住, 宽度是纪律的投影 |
| Q3 战士宿命+引擎语言 | **宿主 skill 为常态 + W5 常驻规划者 MVP(Python 先行)**; 哪个部件实测慢哪个换 Go/Rust(Go 边车触发条款), 核永不换 | 瓶颈在 LLM 延迟不在 CPU; 护城河在 Python 层 |
| Q4 C2 边界 | **全套对齐 CSAI 但全部过账本门链**: 取证级默认开; WebShell/Beacon 带授权书挂账+OPSEC 入链+每命令 request-ticket+revert; 关停有清理门核销 | 你已批做; 差异化=唯一账本化的 C2 |
