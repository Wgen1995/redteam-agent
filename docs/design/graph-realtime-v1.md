# 图谱实时演进+行级重跑+活矩阵 设计 v1(2026-10-18)
缘起: 用户质询三件(ARTEX 探索链路动态图/多一切皆issue的可重跑/覆盖矩阵动态演进)。核心机制一句话: **实时=回放的特例**——图谱/矩阵无状态,任意时刻=「该帧之前账本行」的投影函数;游标 t=now 即实时,t=历史即回放,同一机制。

## 一、图谱实时演进(探索链路动态图)
- **增量推送**: SSE 已有(登录门后)。复用本周 O(1) timeline 的 epoch 机制: 客户端带 last_epoch,服务端只推新行——不重传全量。
- **前端帧合并**: 新 timeline 行→按 11 类节点规则映射→图谱 diff(新节点淡入+边生长动画,压缩节点聚拢);探索链路页同步追加步骤卡。
- **帧游标**: 回放条拖动=切换投影域(≤t);顶部黄条「历史视图 [回到最新]」;实时态=游标吸附最新(可暂停吸附)。
- 对 ARTEX: 它的链路是事件流的自然堆叠;我们的每帧可精确重建+验真(链完整性)。

## 二、行级重跑(借鉴 multica 一切皆issue,超越为「一切皆账本行」)
- 每行可寻址: 表+行号+行哈希=全局唯一地址(已有,补显式化)。
- **重跑操作族**(CLI+右键菜单):
  - re-run intent: 新 intent 行带 derived_from=<原行址>;过审批门(风险级同源);图谱画血缘边(旧→新,虚线=重跑代)。
  - re-verify fact/finding: 走机械重放链,结果新行;两代差异自动对照(实验法制件)。
  - cancel: 撤租约先落账再杀(既有律)。
- **比 multica 强**: issue 重开只有状态翻转;我们重跑有全账(谁发起/为何/过没过门/两代结果对照),且可回放比较任意两代。
- 血缘深度展示: 节点 hover 显示全部祖先链(帧号串联)。

## 三、覆盖矩阵动态演进
- **活矩阵**: 从终态冻结件改为活投影——每 fact/finding/意图完成即重算格子(资产×意图族,深度=对数色阶,未测=斜纹);帧游标同样适用(回放当时覆盖)。
- **冻结矩阵保留**: CONVERGED 时快照存档(现有 P4 冻结语义=收敛证据,不废)——活矩阵=进行时,冻结矩阵=结算时,双轨。
- 覆盖率曲线随帧生成(收敛条件「覆盖率≥95%」从此有动态读数,不再是结算时才算)。

依赖: 全部地基已在(O(1)/epoch/血缘边/SSE/租约)——零新底座。
