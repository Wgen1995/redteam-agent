# GraphLed 智能体编制设计 v1(2026-10-18,基线=ARTEX 8 岗实弹)
ARTEX 编制哲学=**认领制分工**(worker 领一条意图→写回图谱→停)——与我们 intents 租约制**同宗**;分野在执法与验证。

## 八岗对照与判词
| ARTEX 岗位 | 我们对应 | 判 |
|---|---|---|
| goals 目标拆解(工具2) | 八问建战+objective→intents 分解(W5 规划者 MVP 承担) | 已排;超点=拆解结果入链可回放 |
| planner 规划(工具20,每任务一循环,只补未覆盖方向) | 常驻规划者 W5(事件源=timeline 行增长+500ms debounce+六门前置,A:D1 规格已在)+意图路由 priority 公式已在协议 | **已排**;超点=规划状态全在账(它重启丢链,A:D4) |
| mainagent 人机接口(观察+落 hint/高优意图) | **今晚已设计**: 锚定对话+say 指令通道(对话派活必过门) | **已超**——它任务级留言,我们实体级锚定+动作过门+对话入账 |
| worker 执行(领一意图→写回→停,工具12) | 战士+intents 租约(领走/超时回收/双抢拒) | **已超**——同宗认领制+我们每步过四层执法;它 worker 无预算执法 |
| auto 平台操作助手(管任务/资产/建skill,工具26) | CLI 49 命令族=操作面已全;AI 包装=W6「运营助手」岗(过门) | 已排;超点=操作即账 |
| pentest 独立渗透(全链自理,工具6) | battle auto 一键链+九门 | **已超**——它全链无结算门(链断照结),我们 verify-chain 拒结算+清理门 |
| reporter 报告撰写(LLM 写 MD 回写,工具12) | 确定性渲染(同输入同输出钉)+P5.9 | **已超**——LLM 写报告=每次不同不可验;我们确定性重建,客户可复算;可选 LLM 润色层作附录不进正文 |

## 设计律
- 岗位=提示词在册即版本(git)+预算是执法契约(常驻<2000 token 冻结);AI 对话式建岗**不抄**(建执行体=开写路径,必过授权件,C舰 M4 判)
- 认领制+租约+执法=我们编制的骨架;岗位数量不拼(8 岗形态可扩),拼的是每岗的账本纪律
