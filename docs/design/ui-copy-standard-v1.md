# GraphLed 界面文案规范 v1(2026-10-18 定稿)
缘起: 用户点名"看战况/看战果/管战场"垃圾+界面全是黑话。铁律: **界面只说人话**。

## 三条规则
1. 界面用词=行业标准词或页内可自解释的产品词;**内部工程代号一律不上屏**
2. 不造可爱词(看战况/管战场式儿歌禁绝);导航=名词,不用动宾短语
3. 中英不混拼;数字单位明确;按钮=动词+宾语(「导出报告」「批准执行」)
