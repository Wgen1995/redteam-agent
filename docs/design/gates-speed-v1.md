# 门的三速度设计 v1(2026-10-18 用户质询「门太多会不会限制渗透能力」)
北极星判据(宪法#43): 任何门不得增加漏报率/延误火力;门的等待方式是问题,门本身不是。

## 三速度
1. 疾速档: 授权范围内+只读+非破坏(侦察/枚举/指纹/挖洞主面)=零审批直跑
2. 预授权档: L3 工具族=批一次放一族(bounds: 工具+参数域+时长+资产域;出界即停;每次执行仍入账)
3. 严审档: 范围变更/外发/破坏=永人工(法务红线)

## 配套
- 门拒必带改道提示(REJECT=不行+为什么+怎么走;战士不停摆,A:F1 同哲学)
- 预算琥珀线自动求增(通知+一键,非硬死)
- 档位旋钮(强度档已有)+预授权族=CSAI 三模式同能力+更强审计

## 实施量
预授权族表(approvals 扩: family 行+bounds+expire)+批量放行核验+改道提示文案族 ≈ 400 行,并入 W3 收口/W6 审批中心。
