# 人话驾驶舱蓝图(功能27终稿方向)· 2026-10-20

> 宪法62(屏上词过人话滤网)+63(五秒三问)+用户三次怒改的方向固化。驾驶舱舰施工的唯一正文。

## 总则
1. **首页=四问直答**,别的都让路:
   - 打出什么漏洞了? → 漏洞榜(只有验真的;每枚带: 名字/多严重/在哪/证据袋)
   - 正在打什么? → 活池实时(几个士兵/各自在干啥/下一枪打哪排行——规划者舰产物直投)
   - 什么在等我? → 收件箱(审批·求助·任务卡确认,按「等久了」排,同类聚合一票)
   - 花多少钱? → 消耗表(本仗 token/美元,预算帽余量条)(ARTEX 实时消耗表同型)
2. **五秒三问律自检**(63律): 每页设计稿必须写明「这页五秒能答的三问」,答不出的元素砍掉。
3. **全站词表强制**(62律): finding→漏洞 / intent→任务 / warrior→士兵 / credential→钥匙 / asset→目标(机器·入口) / EV卡→证据 / ledger→战账 / distill→战果提炼。屏上出现词表外黑话=验收不过。
4. **会话即对象**: 对话流=一等导航对象;任何页面 @引用 可跳。
5. **空状态人话**: 「还没打过仗——在下面聊天框说『打 xxx.com』开第一仗」;禁空目录裸表格。

## 信息架构(25页砍到6面)
首页(四问) / 任务页(会话流+tabs: 概况·地图·活池·漏洞·消费·日志——ARTEX任务内二级导航同型) / 漏洞页(全量+证据袋+上次验真X天前+待复验队列) / 知识库页(打法卡+哨兵规则+蒸馏草稿人审) / 收件箱(审批+求助+批量) / 设置(预算帽·预授权白名单·范围)。

## 三层验收(驾驶舱舰完不成不算完)
①每页五秒三问写进代码注释与验收单 ②词表过滤脚本进CI(黑话扫描器) ③真数据全通(无假数占位——大合并数据管道复用,api_v2 系列直投)。
