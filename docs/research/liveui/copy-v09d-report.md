## 3. 数据不动律的落实

- 证据卡内原始请求/响应/命令输出（pre.out 区）一律原样；工具卡三态、时间戳、哈希原值不动。
- EV-/FD- 前缀仅在**显示层**剥除（`replace(/^EV-/, "")`），API/账本数据与锚点参数仍用原编号（锚定跳转功能不变）。
- GATE_STATE/REPLAY_STATE/CELL_STATE 的**键**（PASS/PENDING/reproduced 等）=数据面不动，仅 label 值换人话。
- metrics 臂值「处置」是数据，显示层经 ARM_CN 映射为「试验」，数据本体不改。
- opencode-run 字样不再出现在任何用户可见文案（原 session footer/空态已改写）；文件名仅存于数据与内部注释层。
