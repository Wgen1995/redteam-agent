## 0. 全局观感（实证汇总）

- **信息架构**：单页应用，hash 路由（`#dashboard`…）。左侧 224px 常驻侧栏分四区：工作台 / 安全作业 / 能力中心 / 平台管理；「安全防护」「资产管理」「C2」「MCP」「知识」「技能」「智能体」「角色」为可展开分组（router.js 实证：`hitl`、`tool-guard` 挂在 `data-page="security"` 分组下，安全防护**无独立页面**）。全部 29 个页面路由 + 登录层均已走访截图。
- **单页常驻 DOM**：所有视图与隐藏弹窗表单同时挂载在 DOM 中（全站 272 个 input、登录层隐藏保留、每页可见元素 6500~9500 个）——切换视图即显示/隐藏，不重新加载。
- **视觉语言**：浅色主题，body 底 `rgb(248,249,250)`、正文 `#1A1A1A`、系统字体栈；主强调色 `--accent-color:#0066ff`（hover #0052CC，暗色备用 #60A5FA），danger #F87171/#DC2626、success #4ADE80；内容卡白底、圆角 16px、大软阴影（0 24px 48px rgba(0,0,0,.12)）；按钮圆角 10px。

- **国际化/自适应**：顶栏「跟随系统 / 🌐 中文」语言切换、API 文档与 GitHub 外链；CSS 含 `--m-*` 移动端变量与 glass 模糊面板，说明有移动端/暗色适配层。

## 2. 分区要点

**工作台**（01-05）：仪表盘是运营总览（KPI/风险/队列/工具/事件/能力六段式）；对话是主作业入口（项目绑定+模式+审批开关+模型选择）；安全防护=人机协同（HITL 审批引擎可切人工/审计 Agent）+调用拦截（tool-guard 规则引擎，顺序匹配、`{match}` 模板、服务端同步状态）。
