智能渗透 Agent
测评时间：2026 年 Q2
（ 第 一 期 ）


测评背景与目的
大语言模型正在从“给出安全建议”走向“自主规划、调用工具并完成攻击链”的智能渗透 Agent。不同 Agent 在
任务分解、工具编排、上下文管理、记忆、监督纠偏和结果验证方面差异显著；同一 Agent 接入不同模型后，也会
呈现明显的能力与资源差异。仅依靠项目演示或单次案例，难以对系统的真实能力做横向比较。

为什么需要统一测评
在相同题集、环境、流程和评分规则下比较 
Agent 与模型组合，尽量排除调度策略、答题
顺序和外部环境差异对结果的干扰。
本报告关注什么
聚焦 Agent、模型及二者组合的最高公开成功
率、耗时、Token 与六大能力域表现，为技术
研究和方案选型提供数据参考。
TSecBench 的定位
由腾讯安全云鼎实验室推出，面向自动化红队与
对抗性 AI，通过真实漏洞、生产级靶场和云原
生环境衡量自主渗透能力。
公开透明与可复现
平台持续扩展榜单，并逐步公开完整测评日志及
大模型对话记录；详细结果与 Agent Trace 统
一在官网查看。
基于 TSecBench 统一评测体系，对国内外代表性智能渗透 Agent 与国内主流大语言模型开展组合评测，并以每个 
Agent×模型组合三轮测试中的最高成功率结果，观察能力上限、系统适配与效能差异。

04
并列处理
若三轮最高成功率相同，依次选择总耗时更短、总 Token 更少、轮次更早的结果。该口径用于观察组合的公
开能力上限，不代表典型运行均值。详细题目过程、原始结果与 Agent Trace 请访问 TSecBench 官网 ⾭。
Kimi K3 的组合上限最强
13 个 Agent 的选定结果汇总成功率为 77.03%，
在 11 个 Agent 内取得该 Agent 的最高模型组
合成绩。
Cairn 的跨模型上限最高
四个模型各取最优轮次后，汇总成功率达到  
77.70%，在 13 个 Agent 中排名第一。
时间限制02
一般题目最长运行 1 小时；多阶段渗透为特例，
最长运行 2 小时；超时视为未通过。
评测方式与统计口径
TSecBench v1 共 63 道题，覆盖 Web 漏洞挖掘、二进制漏洞挖掘、漏洞利用、多阶段渗透、云攻击和对抗规避六大
能力域。本次公开数据包含 13 个 Agent、4 个模型（Kimi K3、GLM 5.2、DeepSeek-V4-Pro-Preview、MiniMax 
M3）、每个组合 3 轮，共 156 份结果。所评测的模型对象即上述四款在评测期间的对应版本，不包含此后发布的新
模型或模型新版本。
