### 1.2 CLI 面: 26 个入口从来是一等公民,但「输出工艺」无人管

- **深度九成**: cli/ 目录 26 个入口实录(tanyin-ledger 49 条命令/tanyin-runner/tanyin-guard/tanyin-egress/tanyin-canary/tanyin-replay/tanyin-report/tanyin-budgetctl/tanyin-gateloop/tanyin-phases/tanyin-viz/tanyin-selfcheck/tanyin-knowledge/tanyin-evals/tanyin-install + webui/),账本/执法/看门狗/度量全在 CLI 面(docs/design/architecture-map-v3.md:193)。
- **短版照骂**: 启动 web 面 still `cd cli && python -m webui.server`(server.py:34、:830),`tanyin serve` 单命令 USER-CHARTER 标红未清账(docs/USER-CHARTER.md:8);**无统一 `tanyin` 入口、无 --json 输出契约、无统一退出码、无 TUI、无 watch 观战**(01-架构专家.md:44 同判)。VulnClaw 有 19 条 Typer 命令+Rust TUI 5,355 行+REPL+doctor 体检+`--stream` NDJSON(docs/research/2026-09-24-vulnclaw-analysis.md:7、:16;vulnclaw-live-trial.md:49、:61)——**命令面广度我们 26:19 反超,输出工艺我们 0:5 落后**。
- **CLI 面诚实成数**: 深度 9/10,输出工艺 **2/10**(回执是 OK\tID 裸 TSV,给人看的排版/颜色/表格/进度一概没有,更没有测试钉)。

### 1.3 锚点对账: 11 类节点词汇是「待建资产」,不是已建资产(诚实校正)

用户喜欢的 11 类词汇当前长在 **ARTEX 探索链路页**上:节点标签 起点/目标/意图/事实/漏洞/压缩+彩色门徽,边标签 意图链/产出/派生,筛选六类 目标/意图/事实/漏洞/提示/压缩(docs/research/liveui/2c-artex-visual-baseline.md:39;walk-artex-live.md:76-82)。我们 graph.html 现在是 **6 层+10 边**词汇(graph.html:335-341)——目标/意图/事实/发现/证据对得上,**起点/漏洞/提示/压缩/派生/意图链/产出/证明 8 个词还没进图谱**。方向已获用户认可(「如果我们使用账本+图谱,也可以要这样」),落地见第④节 P0-3 与第⑤节。

**一句话总判决**: 双面骨架都是真的——Web 面九页+五钮+急停确认+锁定+有测试钉的工艺纪律,CLI 面 26 入口+49 命令;但按「超越五产品」的尺子,**Web 面功能广度刚到 ARTEX 的零头,CLI 面输出工艺刚到 VulnClaw 的零头,用户点名的「图谱不断演变」还一个字没兑现**。综合 **4/10**。

## ③ 差距(照骂,按疼度排序)

1. **最急合规洞(03 舰已判,UI 面再钉一次)**: /new 表单只收 4 字段(name/scope/budget/note,new.html:447-452),**授权八问在界面上零体现**;后端把授权四件写成场景占位——`--auth-doc=AUTH-WEBUI-<N>.pdf` 文件不存在,sha256=「名称+时刻」指纹不是授权书指纹,靠 `--allow-missing-auth=1` 豁免开战(server.py:516-523)。账本本身支持真授权件校验(cli/ledger/write_cmds.py:304-324:auth 文件在场则验 sha),**是 UI 把宽门走成了豁免门**。从浏览器开的每一战都顶着虚拟授权书,这在我们自己 report_lint 里就是「授权书缺」级瑕疵(cli/ledger/report_lint.py:276)。
2. **用户点名的「图谱不断演变」一个字没兑现**: graph 页 10 秒全量重拉+整画布重画(graph.html:865),无增量、无新节点入场提示、无演变动画、无 digest 压缩节点;词汇 6/11。用户原话「不断渗透图谱不断演变」=图谱是活运行面(docs/USER-VERBATIM/recovered-2026-10-16-whitebox.md:11)——现在它是一张 10 秒翻新的地图,不是运行面。
3. **发现没有生命周期**: 高危置顶流不等于管理。无三态终审、无确认率、无复测入口、无「按此任务筛选」。ZhuLong 靶场侧 13 条被打出的 findings 都有三态终审和 CVSS 向量串(usage-guide-zhulong.md:77-79),我们打人家的靶场,自己界面的发现管理还不如人家。
4. **报告只有一个下载钮**: ARTEX 把报告当一等公民整页渲染+复制+时间戳(usage-guide-artex.md:271),我们连「看一眼」都不行,只能下 zip。
5. **审批是一张卡不是一个面**: 无待审队列页、无历史审计表(申请/决定双时间戳)、无拦截规则管理。CSAI 把规则闸门与人工审批分立且规则层挡掉 100% 危险操作(live-recon-1.md §1.5)——我们的 tanyin-guard 规则在 CLI 有,界面上看不见。
6. **实时模型落后一代**: 三页死页(session 对话页零自动刷新=「对话」是录像不是对话)、三页全量重拉。ARTEX 的可靠性模型(单 SSE+seq 去重+断线可见)是现成答案(usage-guide-artex.md:233)。
7. **CLI 输出工艺裸奔**: 26 个入口没有一个 `--json`,没有统一退出码,没有给人看的表格/颜色/进度;`tanyin serve` 红项未清(docs/USER-CHARTER.md:8)。双面一等公民的「CLI 面」现在只有深度没有体面。
8. **多战场切换是跳转不是切换**;无战场列表页、无批量操作、无并排战况。
9. **Token 三段经济学缺失**: ARTEX 缓存命中率 95% 是成本叙事主角(live-recon-1.md §2.2),我们预算条只有「余量/硬顶」,模型侧账根本没有三段口径。
10. **activity 页无过滤无暂停追尾**(grep 实测全页 3 控件级);metrics 统计术语残留(上轮 F4 判过,替词表已立但未逐页扫尾)。

## ⑤ 独有优势放大法: 11 类节点词汇=资产,哈希链=别人抄不走的放大器

### 5.1 词汇→账本表天然映射(这套词汇简直是为我们的账本量身定的)

| 词汇 | 账本单源 | 备注 |
|---|---|---|
| 起点 | timeline 首行/建战事件(server.py:518 add-goal 回执行号) | 一战一起点 |
| 目标 | goals.tsv | architecture-map-v3.md:83 |
| 意图 | intents.tsv | 「要么验证要么 blocked,不许蒸发」同款纪律 |
| 事实 | facts.tsv | |
| 漏洞 | findings.tsv | 可被 supersede——「派生」的天然素材 |
| 提示 | knowledge/ 钩子+guard 规则提示 | 新增轻表或在 edges 加 hint 类 |
| 压缩 | digest(新):复用 v0.8 chain 稳定器语义,链收口=压缩节点 | cli 命令 chain-create/advance/ls 已在册(architecture-map-v3.md:163) |
| 派生 | edges.tsv derived_from | 十种边里已有(graph.html:338) |
| 意图链 | chain(v0.8 已有命令面)+edges | **账本已有、图上没画——白捡** |
| 产出 | edges yields | 已有 |
| 证明 | E-index+evidence 卡+edges proves | 已有 |

结论: **11 个词里 7 个在账本里现成躺着,2 个要加轻投影,2 个(提示/压缩)要立新约定**。ARTEX 这套词汇是引擎内部状态的投影;我们落这套词汇,每一类都直接落在有哈希链的表上——**词是它的,底座是我们的**。

### 5.2 为什么五家做不了「不断演变」而我们能(放大器)

1. **演变回放条(独有,零成本站上)**: timeline.tsv 是链式哈希、行号即顺序(01-架构专家.md:24)——图谱可以按 timeline 行号做**逐帧重放**:拖动时间轴,画布回到任意历史时刻,节点/边按落账顺序重新生长。ARTEX 的图是引擎内存状态快照,没有不可篡改的时序账,做不到精确重放;VulnClaw 无图谱;CSAI 攻击路径是事实关系静态图。「不断渗透图谱不断演变」在我们的底座上不只是动画,是**可审计的演变**——这是把用户一句喜欢,做成五家都抄不走的功能的唯一路径。
2. **压缩节点=战地记忆可视化(治理卖点)**: ARTEX compactor 55 个 digest 节点解决长战役上下文膨胀(walk-artex-live.md:77-82)。我们的对应物=意图链收口:一条链 blocked/verified 时折叠为单节点,保留结论丢过程、链编号可回查。在界面上这同时回答了审计问题「你这仗中间干了什么」——展开链=完整过程,折叠=干净战场。
3. **双面同源放大**: 图谱投影(projections.py 单源)同时喂 /api/graph.json 和 `tanyin graph --watch/--json`——同一份演变流,浏览器里是动画,终端里是逐行打印。五家没有任何一家同时有 web 图谱和 CLI 图谱,更没有同一个数据源。

### 5.3 放大路线(并入 P0-3/P1-7,不另立批)

词汇落地(11 类)→ SSE 增量(新节点入场脉冲)→ digest 折叠 → 演变回放条(timeline 行号=帧)→ `tanyin graph --watch`。前三步在 P0-3 交付,后两步随 P1-7/P1-8 交付。回放条是我们在「攻击路径图」维度从「平地板」直接跳「独有」的一步,建议列为下下批的旗舰演示件。
