# 探隐开发原则（单源账本版）

> 本文件=开发协作的持久律法。会话会断、记忆会丢，**这里没写的不算数**。
> 增改原则须 commit 入史；违反任何一条=对账时如实披露。

## 协作节奏
- **常开模式**：用户说「开」=开工一批；每批闭环=计划→TDD 实现→验证→落帐 HANDOFF→蓝图翻状态→commit→push（自动推送）。
- **对账式汇报**：讲证据不讲故事；战果=结算器可复算；过程坑如实记录。

## 诚实律
- 不确信记 suspected；未实测标「未实测」；禁止伪造。
- 执法缺口/工具盲区/外部故障如实披露（例：b27 预算空铸、b31-34 API 断连全灭）。

## 记账律
- **对话内承诺=账外承诺=违规**：凡「待做/在跑/等结果」即刻镜像 HANDOFF「⏳ 进行中」节，做完划走。
- **单边更新=制造说谎的镜子**：蓝图双胎（architecture-map-v3.md + panorama/tanyin-architecture-v3.html）必须同步翻。
- **版本表加行≠蓝图更新**：每批落账须对正文实勘比对（机制面/数字/状态符）。
- **不依赖记忆的纪律才算纪律**：原则、状态、教训都以文件+git 为准。

## 边界律（仓外纪律）
- ZhuLong monorepo 工作目录**只读研究**，绝不修改。
- `pantero/` 目录**不碰**。
- 工具不越权：scorer 不代跑代理；rerun 只聚合不代跑战斗；settle 只结算不改账。

## 机制哲学
- 照亮不击杀（LOGONLY-ALIVE）；防幻觉零分律（无重放实证不计分）；哈希链护体（改账=断链=可检）。
- 人工触点全场唯一（P5.5 签发）★；人类事项显式列出。

## 环境事实
- 电脑重启=烧掉在打的战（已发生 2026-10-11 00:24）；重启前喊一声。
- `/tmp` 日志易失；持久数据在 `~/.tanyin/`（战）与 git（工程）。
