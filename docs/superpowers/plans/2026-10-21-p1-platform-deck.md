# P1 任务书·平台面+地基件(2026-10-21 起,总案 v4 §P1 裁定范围)

> 铁律承 P0(docs/superpowers/plans/p0-execution-ledger.md 工艺教训全数有效)。
> **引擎解禁但从严**: v4 已批引擎三小件+plan 模式;其余引擎码仍零改。
> 引擎件纪律: TDD 先红后绿;引擎既有回归(battle.py 靶场/tests 套件)全绿才落;
> 行为变化须带开关或向后兼容,绝不静默改语义;每次落地→账本→push。

## 范围(v4 原文)
平台面(20 页 IA 实页化)+enrich 资产自动补全+evidence 证据仓(内容寻址 blob+
24h GC 宽限+报告版本冻结导出)+plan 模式(侦察→作战计划→你批→转执行)+
引擎三小件(停止前钩子/递归深度帽/会话级 MEMORY)+Go 边车(流量录制)+SQLite 只读索引。

## 任务队列(序=依赖序,每任务一舰+父逐舰验收)

### U1 引擎·停止前钩子 stop-hook
norma 吸收: 收仗时挡未决(待审/未落定项不让仗无声收尾)。引擎生命周期挂点+
fail-closed;账本留痕;既有回归全绿。

### U2 引擎·递归深度帽 recursion-cap
subagent 递归守卫: 深度帽可配,超帽拒建子兵并留痕;缺省值保守。

### U3 引擎·会话级 MEMORY session-memory
会话内跨轮记忆(战士级,P4 才升长期);引擎侧存取原语+账本纪律。

### U4 plan 模式·引擎侧
侦察意图→产出作战计划文档(账本新留痕类)→待批态→批准转执行态。引擎状态机
最小增量,不动既有九门流程主干。

### U5 plan 模式·指挥台侧
say 识别 plan 请求→计划卡(计划全文+风险+预算+范围)→你批→转执行回执。
授权哲学不退: 确认+预算两问+范围红线照旧。

### U6 evidence 证据仓
内容寻址 blob 仓(sha256)+24h GC 宽限+报告版本冻结导出;证据袋从「账本引用」
升「独立仓库」;读面 API+账本互链哈希核验。

### U7 SQLite 只读索引
TSV 链账→SQLite 只读投影(发现/资产/时刻流加速);单源仍是账本,索引只读可重建。

### U8 平台页·作战组
/dashboard 仪表盘(跨仗统计)/任务页挂 IA 入口(现 /tasks IA 外)/assets 资产与
覆盖(+自动补全中态占位)/fleet 舰队(多仗列队)。全走 ledger_reader/索引,零假数。

### U9 平台页·机组组
/tool-runs 工具执行流水/llm-recordings LLM 录制库/reports 报告(签发+冻结导出
接 U6)/knowledge 知识库(复盘蒸馏)。

### U10 平台页·系统组
/approvals 审批中心(跨仗待审队列,指挥台气泡同源)/intercepts 拦截规则五段
(引擎侧配置如实读)/agents 智能体(在编战士册)。

### U11 enrich 资产自动补全池
后台非 AI 工作池: 域名→dnsx 解析+HTTP 探测(经录制代理),自动长 IP/端口节点+
resolves/exposes 边+attrs;**RoE 门控 HTTP**;补全结果入账可追溯。

### U12 Go 边车·流量录制
P0 钩子→P1 Go 边车;traffic 页接线(回放面板);录制与账本时间线互链。

### U13 P1 收官三验
四门全测+活体+E2E 扩程(平台页入冒烟)+账本收口+START-HERE 翻新。

## 验收基线(每舰)
先红后绿真 rc;引擎件加跑引擎回归;活体 curl 面;pathspec 提交;账本行;push。
父逐舰独立复验,舰连亡即父接管(P0 先例)。
