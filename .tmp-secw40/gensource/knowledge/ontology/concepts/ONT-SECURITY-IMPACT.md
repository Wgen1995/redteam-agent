# ONT-SECURITY-IMPACT：安全影响

## 定义

安全影响是安全保护被破坏后的实际损害后果——当可控数据到达Sink、状态转换违反不变量或资源消耗失控时，对资产的机密性、完整性或可用性造成的损害。

## 包含边界

- 机密性损害：敏感数据泄露（凭证泄露、个人信息泄露、源码泄露）
- 完整性损害：数据被篡改（数据库记录被修改、配置被篡改、日志被伪造）
- 可用性损害：服务不可用（拒绝服务、资源耗尽、系统崩溃）
- 权限提升：攻击者获得了超出授权范围的权限
- 信任链断裂：认证/授权机制被绕过，系统信任链受损
- 横向移动：攻击者利用初始立足点向系统其他部分扩展
- 供应链影响：漏洞影响下游依赖此系统的用户

## 排除边界

- Sink（ONT-SINK）不是安全影响——Sink是危险操作节点，安全影响是操作后果的损害。
- 可观察预言机（ONT-OBSERVABLE-ORACLE）不是安全影响——可观察预言机是观察损害是否发生的手段，安全影响是损害本身。
- 资产（ONT-ASSET）不是安全影响——资产是被保护的对象，安全影响是资产被损害的后果。

## 关系

| 关系类型 | 目标概念 | 说明 |
|---|---|---|
| `causes` | ONT-SINK | Sink导致安全影响 |
| `causes` | ONT-STATE-TRANSITION | 状态转换违反不变量导致安全影响 |
| `causes` | ONT-RESOURCE-CONSUMPTION | 资源耗尽导致安全影响 |
| `observed_by` | ONT-OBSERVABLE-ORACLE | 安全影响被可观察预言机观察 |

## 正例

```python
# SQL注入导致的安全影响
# Sink: cursor.execute("SELECT * FROM users WHERE name = '" + name + "'")
# Impact: 机密性损害——所有用户凭证泄露
# 攻击者可读取users表中的所有密码哈希

# 命令注入导致的安全影响
# Sink: os.system("ls " + directory)
# Impact: 完整性损害+权限提升——攻击者可执行任意命令
# 攻击者可篡改文件、获取shell、横向移动
```

## 反例

```python
# 这是Sink（危险操作），不是安全影响
os.system("ls " + directory)  # 这是Sink，安全影响是此操作后果的损害
```

## 代码信号

安全影响本身不是代码中的实体，而是分析结论。识别安全影响需要：
- 评估Sink操作的能力边界（SQL注入能做什么、命令注入能做什么）
- 评估资产的敏感度（泄露用户表 vs 泄露配置表）
- 评估信任链的传播范围（单服务受损 vs 整个微服务链受损）
- 评估可逆性（可回滚的篡改 vs 不可逆的删除）

## 生态映射

安全影响是跨生态的通用概念，不因语言/框架不同而变化。不同生态中的典型影响：

| 生态 | 典型安全影响 |
|---|---|
| Web应用 | XSS导致会话劫持、SQL注入导致数据泄露、CSRF导致操作伪造 |
| 智能合约 | 重入攻击导致资产被盗、整数溢出导致逻辑错误 |
| AI/Agent系统 | prompt注入导致指令劫持、工具滥用导致越权操作 |
| 嵌入式设备 | OTA劫持导致固件篡改、调试接口暴露导致设备控制 |
| 微服务 | 服务间信任被滥用导致横向移动、API网关绕过导致未授权访问 |
