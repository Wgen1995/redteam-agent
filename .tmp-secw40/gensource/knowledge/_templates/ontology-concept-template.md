# ONT-XXX：概念名称

> **模板不计入正式知识条目，不构成检测能力，仅供编写时参考。**
> 本文件是编写本体概念条目时的结构参考，不是已确认的知识内容。填写后需经人工复核并纳入变更批次才能成为正式知识。

## 元数据

| 字段 | 值 |
|---|---|
| stable_id | ONT-XXX |
| name | 概念中文名 |
| version | v0.1 |
| source | 来源引用（决策文档编号/行业标准/内部推导） |
| consumers | 消费此概念的GenSource能力列表 |

## 定义

一句话核心定义。

## 包含边界

- 哪些情况属于这个概念
- 列举具体的表现形态

## 排除边界

- 哪些情况不属于这个概念
- 特别是与相邻概念的区分

## 关系

| 关系类型 | 目标概念 | 说明 |
|---|---|---|
| `relation_type` | ONT-YYY | 关系描述 |

> 关系类型取自 `ontology/relation-types.md` 中登记的类型。这些关系只是Markdown引用，不是运行时图。
