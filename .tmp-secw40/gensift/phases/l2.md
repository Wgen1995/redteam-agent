## L2 发散（L1 全闭合后必跑——unknown-unknowns 的唯一合法通道，不可跳过）

```bash
. "$S/env.sh"
BLOCKED=$(awk -F'\t' '$5=="blocked"' "$S/checks.tsv" | wc -l | tr -d ' ')
# 访问上限（防 frontier 永有料导致无限循环）。上限 5 出处与局限（D-102）：R3-R5 回放未见
# 访问 >2 次仍有新产出 + zero_streak≥2 收敛判据双保险丝——保险丝定位而非精调值，宁早停不空转
V=$(( $(cat "$S/audit/l2_visits" 2>/dev/null || echo 0) + 1 )); echo "$V" > "$S/audit/l2_visits"
ZS=$(cat "$S/audit/l2_zero_streak" 2>/dev/null || echo 0)
if [ "$V" -gt 5 ] || [ "$ZS" -ge 2 ]; then
  if [ ! -f "$S/audit/joins-round-done" ]; then
    echo "L2 收敛/上限（visits=$V zero_streak=$ZS）→ 先执行【拼链与合并】（phases/joins.md）——其 follow-up ext 卡回主循环派发"
  else
    echo "L2 收敛/上限（visits=$V zero_streak=$ZS）→ 跳过派发，直接【终态】"
  fi
else
  # 发散输入（B-093 全口径）：blocked 残链 + 未交付候选（merged-into 除外——已由 canonical 承接）
  # + dangling joins（joins.tsv 无对端行）+ guard 离群源（guards 五段含 unknown 的入口——发散靶如实入 frontier）
  awk -F'\t' 'NR>1 && $5=="blocked"{print "blocked\t"$1"\t"$3}' "$S/checks.tsv" > "$S/tmp/l2_frontier.txt"
  awk -F'\t' 'NR>1 && $8!="delivered" && $8!="degraded" && $7!~/^merged-into/{print "open-cand\t"$1"\t"$6}' "$S/candidates.tsv" 2>/dev/null >> "$S/tmp/l2_frontier.txt"
  tail -n +2 "$S/joins.tsv" 2>/dev/null | awk -F'\t' '$2=="NA"||$4=="NA"{print "dangling-join\t"$1"\t"$6}' >> "$S/tmp/l2_frontier.txt"
  awk -F'\t' 'NR>1 && $7~/unknown/{print "guard-outlier\t"$1"\t"$3}' "$S/inventories/source_inventory.tsv" 2>/dev/null >> "$S/tmp/l2_frontier.txt"
  cat "$S/tmp/l2_frontier.txt"
fi
```

```
你是 GenSift Analyzer（发散模式，divergence=true）。读取 {SK}/agents/analyzer.md 的「L2 发散」节并严格遵守。
输入 frontier：{S}/tmp/l2_frontier.txt 的内容。
每条怀疑：锚定 ≥1 账本实体（具体 sink/source/候选 ID），只生成建议新增检查点行
DIV:{锚点ID}<TAB>{怀疑描述}<TAB>{建议}
禁止结论；≤20 条；找不到可锚定的新怀疑时输出零条。
写分片到 {S}/shards/DIV-R{当前轮号}.tsv。完成后只返回一行：条数。
```

DIV 分片验收后转 ext 卡（发散通道的唯一出口是卡，不是结论）：

```bash
. "$S/env.sh"
R=$(cat "$S/audit/round_count" 2>/dev/null || echo 0)
f="$S/shards/DIV-R${R}.tsv"
n=0
if [ -s "$f" ]; then
  while IFS=$'\t' read -r head desc sugg; do
    case "$head" in DIV:*) ;; *) continue ;; esac
    [ "$n" -ge 20 ] && break                    # ≤20 机械封顶
    aid=${head#DIV:}                            # 锚点 ID 在 DIV: 前缀里，不是描述列
    # 锚点级去重：同锚点已有 ext 卡则跳过（与轮号/文件名无关——L2 二次访问不撞号）
    awk -F'\t' -v a="$aid" '$2=="ext" && $3==a{f=1} END{exit !f}' "$S/checks.tsv" 2>/dev/null && continue
    n=$((n+1))
    printf "CK-ext-%05d-%03d\text\t%s\t%s\tunchecked\t\t\t0\tr1\n" "$R" "$n" "$aid" "$aid" >> "$S/checks.tsv"
  done < "$f"
fi
echo "L2: $n 张 ext 卡入账"
# 收敛账本：零新条连计 2 轮 → L2 结束（不靠编排器记忆）
if [ "$n" -eq 0 ]; then
  echo $(( $(cat "$S/audit/l2_zero_streak" 2>/dev/null || echo 0) + 1 )) > "$S/audit/l2_zero_streak"
else
  echo 0 > "$S/audit/l2_zero_streak"
fi
echo "l2_zero_streak=$(cat "$S/audit/l2_zero_streak")（≥2 → 跳过 L2 派发，直接终态）"
# ext 卡下轮由主循环按普通卡派发（2b 的 ext 分支给信封）
```

**不变式轨**（L1 闭合后、终态前，per invariant × module 发 ext 卡——B-084；module 取值域来自回填后的 file_inventory.module，单模块库自然退化为 per-invariant）：

```bash
. "$S/env.sh"
# module 取值域 = file_inventory.module 的**语义模块**（F1：只认 mod: 前缀——dir: 机械回填与 '-' 不算模块，
# 否则 tests/docs 等目录也会领 INV 卡；前缀剥掉再发卡——卡 ID 形态与历史会话一致。无 mod: 时退化为单模块 '-'）
MODS=$(awk -F'\t' 'NR>1 && $5 ~ /^mod:/{ v=substr($5,5); print v }' "$S/inventories/file_inventory.tsv" | LC_ALL=C sort -u | tr -cd '[:alnum:]_.-\n')
[ -n "$(printf '%s' "$MODS" | tr -d '[:space:]')" ] || MODS="-"
# 行业域过滤（B-087/D-073）：recon/industry-domain.md 首行 domain 值 × .inv 头 `# domain:`——
# 不匹配则整包跳过（防零售包污染金融 run）；无域头=通用包全加载；recon 未产出=全加载+披露
DOM=""
[ -f "$S/recon/industry-domain.md" ] && DOM=$(awk -F': *' '$1=="domain"{gsub(/[ \t\r]/,"",$2); print $2; exit}' "$S/recon/industry-domain.md")
SKIPPED=0; LOADED=0
for invf in "$SK"/invariants/*.inv; do
  [ -f "$invf" ] || continue
  IDOM=$(awk -F': *' '$1=="# domain"{gsub(/[ \t\r]/,"",$2); print $2; exit}' "$invf")
  if [ -n "$DOM" ] && [ -n "$IDOM" ] && [ "$IDOM" != "$DOM" ]; then
    SKIPPED=$((SKIPPED+1)); continue
  fi
  LOADED=$((LOADED+1))
  while IFS=$'\t' read -r iid rest; do
    case "$iid" in INV-*) ;; *) continue ;; esac
    while IFS= read -r mod; do
      # 整字段相等比较（grep 前缀匹配在模块名含正则元字符时误判）
      awk -F'\t' -v c="CK-ext-${iid}-${mod}" '$1==c{f=1} END{exit !f}' "$S/checks.tsv" 2>/dev/null && continue
      printf "CK-ext-%s-%s\text\t%s-%s\t%s\tunchecked\t\t\t0\tr1\n" "$iid" "$mod" "$iid" "$mod" "$iid" >> "$S/checks.tsv"
    done <<< "$MODS"
  done < "$invf"
done
echo "不变式 ext 卡总数: $(awk -F'\t' '$2=="ext"' "$S/checks.tsv" | wc -l | tr -d ' ')（module 域: $(printf '%s' "$MODS" | tr '\n' ',')）"
echo "invariants 域过滤: domain=${DOM:-未产出（全加载+披露）} 加载包=$LOADED 跳过包=$SKIPPED（.inv 头 # domain: 不匹配即整包跳过——B-087）"
```

ext 卡产生 candidate 时走 3d 落账：INV 卡 → `CD-INV-{inv_id}-{module}`（双命名空间可反推；module 取 file_inventory.module，单模块退化无 module 时用 `core`——S10 裁决）；锚点可解析到 SINK-/SRC- 的 → `CD-{sink:05d}-{source:05d}`；不可解析锚点 → `CD-X-{origin}`（origin=锚点 ID；I14 披露不参与反推）；term 卡候选 → `CD-F-{file_seq}`（第三实体段，可由 file_seq 反推）。
