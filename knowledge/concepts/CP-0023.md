## 场景

API 漏洞测试:BOLA/IDOR 水平越权;批量分配(未过滤字段提权);认证绕过(JWT/Token 缺陷);GraphQL(嵌套查询/内省/泄露);速率限制缺失(枚举与爆破面)。

## 步骤

1. API 面测绘:文档(OpenAPI/Swagger)/前端 JS 分析/隐藏端点枚举【纪律:无】
2. 对象级授权:双账户对照,改对象标识验证横向越权【纪律:无】
3. 功能级授权:低权限调用高权限端点面【纪律:无】
4. 批量分配:提交额外字段测试未过滤属性提权【纪律:无】
5. GraphQL 面:内省/嵌套深度/字段级授权(内省禁用时用错误泄露推断)【纪律:无】
6. 速率限制面:枚举与爆破可行性评估(方法论级,不实际爆破)【纪律:无】

## 工具引用

- API 测试代理(Burp 同型): 请求构造与对照
- GraphQL 探测工具: 内省与深度测试
- OpenAPI 文档解析: 端点清单

## 纪律标注

- L3: 无(API 交互在授权目标内)
- 外发: 无(不导出真实用户数据;越权验证用测试账户对)
- 回滚: 无(只读验证优先;写操作须最小影响+可逆)

## 证据标准

- 完整 HTTP 请求(含测试载荷)与响应
- 越权/泄露成功证明
- 漏洞类型标注与影响简述

## 边界

- 不得删除或修改生产数据
- 写操作最小影响;真实用户数据不导出
- 法律敏感:本卡只写方法论与判定标准;示例仅限本方靶场内验证,不提供现成可执行武器(载荷/命令/利用代码)。
