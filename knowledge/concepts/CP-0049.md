## 场景

Web 应用完整渗透流程:技术栈识别→目录枚举→认证测试→输入验证测试(注入族)→逻辑漏洞测试(越权/业务/竞态)→输出报告。深入知识转 Web 高级域。

## 步骤

1. 技术栈识别:响应头/前端分析/后端框架与 CMS【纪律:无】
2. 目录枚举:常见目录/敏感文件/API 文档面【纪律:无】
3. 认证测试:默认凭据/爆破检测面/会话管理/JWT 面【纪律:无】
4. 输入验证测试:注入族(SQL/XSS/SSRF/包含/命令/上传)逐类过卡【纪律:无】
5. 逻辑漏洞测试:越权(水平/垂直)/业务绕过/竞态/支付面【纪律:无】
6. 输出:渗透报告+PoC 级证据链【纪律:无】

## 工具引用

- fetch/HTTP 客户端: 响应采集
- chrome-devtools 同型: 前端分析
- Burp: 重放与对照

## 纪律标注

- L3: 无(授权目标内交互)
- 外发: 无
- 回滚: 无(读面优先;写操作最小影响)

## 证据标准

- 六段各自结果记录
- 发现带 PoC 级证据(请求/响应/复现步骤)

## 边界

- 不超出目标边界;证据不伪造不夸大
- 发现计分须证据可重放
- 法律敏感:本卡只写方法论与判定标准;示例仅限本方靶场内验证,不提供现成可执行武器(载荷/命令/利用代码)。
