## 场景

跨站请求伪造:无 Token 保护;Token 可绕过(删除/置空/不绑定会话);JSON CSRF(Content-Type 限制绕过);SameSite 绕过(子域/顶级导航)。

## 步骤

1. 状态变更操作盘点:写操作端点与防护机制盘点【纪律:无】
2. Token 面:可预测性/会话绑定/删除与置空行为【纪律:无】
3. SameSite 面:cookie 属性/子域可控点/GET 副作用【纪律:无】
4. 内容类型面:JSON 端点的跨域提交可行性(结构级验证)【纪律:无】
5. Referer 面:空 Referer 与子串匹配缺陷【纪律:无】
6. PoC 构造(结构级)+受影响操作评估【纪律:无】

## 工具引用

- PoC 页面模板(结构级): 触发验证
- Burp: 请求对照

## 纪律标注

- L3: 无
- 外发: 无
- 回滚: 无(验证用测试账户;写操作最小影响)

## 证据标准

- CSRF PoC 页面(结构级)
- 跨域请求成功执行证明
- 受影响操作与影响评估

## 边界

- 不得对真实用户发起 CSRF 攻击
- 写操作用测试账户+可逆数据
- 法律敏感:本卡只写方法论与判定标准;示例仅限本方靶场内验证,不提供现成可执行武器(载荷/命令/利用代码)。
