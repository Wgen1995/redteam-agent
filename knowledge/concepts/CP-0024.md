## 场景

认证机制漏洞:弱密码策略(暴力破解/凭据填充面);JWT 缺陷(算法降级/密钥混淆);OAuth 缺陷(redirect_uri 篡改/CSRF);会话固定(登录前后会话不变);MFA 绕过(状态跳过/竞态)。

## 步骤

1. 认证面测绘:登录端点/令牌形态/会话 cookie 属性/MFA 流程【纪律:无】
2. 密码策略与锁定行为观察(锁定阈值与复位逻辑;不做真实账户锁定攻击)【纪律:无】
3. 令牌类:JWT 算法与签名验证缺陷(降级/混淆/注入类,靶场验证)【纪律:无】
4. OAuth/联合登录:redirect_uri 校验/state 防 CSRF/令牌传递面【纪律:无】
5. 会话管理:固定/并发/过期/属性面【纪律:无】
6. MFA 面:状态机跳过/备用通道/竞态窗口【纪律:无】

## 工具引用

- API 测试代理: 认证流重放
- JWT 解析工具: 令牌结构检查
- 竞态测试工具: 并发窗口验证

## 纪律标注

- L3: 无(授权目标内交互)
- 外发: 无(凭据测试仅自建测试账户)
- 回滚: 无

## 证据标准

- 完整认证绕过请求链
- 绕过成功证明(会话/受保护资源访问)
- 漏洞类型标注与影响范围

## 边界

- 不得对真实用户账户执行锁定攻击
- 凭据填充仅方法论评估+自建账户验证
- 法律敏感:本卡只写方法论与判定标准;示例仅限本方靶场内验证,不提供现成可执行武器(载荷/命令/利用代码)。
