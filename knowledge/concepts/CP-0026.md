## 场景

点击劫持:X-Frame-Options 缺失;CSP frame-ancestors 绕过;拖放劫持;多步操作组合。

## 步骤

1. 框架保护检查:XFO/CSP frame-ancestors 逐页面盘点与一致性核对【纪律:无】
2. 遗漏路径发现:例外页面/子域/旧版本面【纪律:无】
3. JS 防护评估:framebusting 脚本对 sandbox 属性的耐受【纪律:无】
4. PoC 页面构造(靶场内):iframe 嵌套+可加载证明【纪律:无】
5. 敏感操作影响评估【纪律:无】

## 工具引用

- PoC 页面模板(结构级): 嵌套验证
- 浏览器开发者工具: 响应头检查

## 纪律标注

- L3: 无
- 外发: 无
- 回滚: 无

## 证据标准

- PoC 页面(iframe 嵌套结构)
- 可在 iframe 中加载的证明截图
- 受影响敏感操作评估

## 边界

- 不得对真实用户实施点击劫持攻击
- PoC 仅结构级不含诱导内容
- 法律敏感:本卡只写方法论与判定标准;示例仅限本方靶场内验证,不提供现成可执行武器(载荷/命令/利用代码)。
