## 场景

XML 外部实体注入:经典 XXE(文件读取);盲 XXE(OOB 外带);参数实体(DTD 嵌套);XInclude(非 DTD 环境);SVG/DOCX 载体(上传触发)。

## 步骤

1. XML 入口盘点:API/上传/文档处理面【纪律:无】
2. 解析器行为画像:DTD/外部实体/参数实体支持度【纪律:无】
3. 文件读取验证(经典/参数实体路径,敏感文件用靶场测试文件)【纪律:无】
4. 盲 XXE+OOB 验证(外带仅靶场回传点观测)【纪律:外发】
5. 载体面:SVG/DOCX 上传触发的解析链验证【纪律:无】
6. 可读取范围评估与证据归档【纪律:无】

## 工具引用

- Burp: XML 请求构造
- OOB 回传点(靶场自建): 盲注验证
- 文档构造工具(结构级): 载体验证

## 纪律标注

- L3: 无(目标内交互)
- 外发: 步骤 4 OOB 外带仅限靶场自建回传点;禁读目标之外的系统文件
- 回滚: 无

## 证据标准

- 完整 HTTP 请求(含 XML 结构)与响应
- 实体解析证明(文件内容/回调/外带数据)
- 可读取范围评估

## 边界

- 不得通过 XXE 读取当前目标之外的系统文件
- OOB 回传点仅靶场自建
- 法律敏感:本卡只写方法论与判定标准;示例仅限本方靶场内验证,不提供现成可执行武器(载荷/命令/利用代码)。
