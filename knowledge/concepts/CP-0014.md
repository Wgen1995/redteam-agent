## 场景

CTF Misc 题型:Python/Bash 沙箱逃逸;编码链识别与逐层解码;QR/音频/图像隐写;游戏与自定义 VM 逆向(WASM/Brainfuck/Z3 约束求解);竞赛平台 API 操作;Linux 提权速查(SUID/sudo/cron/内核)。

## 步骤

1. 快速判题:按题目特征(输入框形态/受限 shell/异常字符串/二进制载体)定位考点【纪律:无】
2. 编码链处理:识别多层编码,逐层解码逐层验证【纪律:无】
3. 隐写分析:载体类型识别(QR/音频/图像)+提取工具链【纪律:无】
4. VM/游戏逆向:指令集分析+约束求解【纪律:无】
5. 沙箱逃逸:枚举可用内建与逃逸向量,本地验证(方法论级)【纪律:无】

## 工具引用

- Z3 约束求解器: VM/逻辑题求解
- binwalk: 载体文件分析
- 隐写分析工具族: 按载体类型选型
- 代码执行环境: 解码与逃逸验证
