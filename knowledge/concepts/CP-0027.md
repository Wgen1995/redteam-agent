## 场景

云平台漏洞:IAM 错配(过度权限/角色链);存储桶泄露(公开读/列举);元数据服务(IMDS 凭据);Serverless(环境变量泄露);K8s(ServiceAccount 提权)。

## 步骤

1. 云面测绘:资产/区域/IAM 策略面/存储与函数清单【纪律:无】
2. IAM 枚举:策略过度权限/角色链可达性/条件键面【纪律:无】
3. 存储面:公开性与列举可行性(授权资产内)【纪律:无】
4. 元数据面:SSRF 可达性与 IMDS 版本(凭据仅证明存在,靶场内验证)【纪律:外发】
5. 函数与编排面:环境变量泄露/ServiceAccount 权限【纪律:无】
6. 影响评估:横向移动可行性与范围【纪律:无】

## 工具引用

- 云 CLI(授权凭据): 资产与 IAM 枚举
- 云安全配置审计工具: 错配面
- K8s 客户端: 编排面枚举

## 纪律标注

- L3: 云 API 交互走授权凭据与 egress 白名单
- 外发: 步骤 4 元数据凭据仅证明存在性,不导出真实凭据(靶场内验证使用)
- 回滚: 无(读面为主;任何资源配置改动禁做)

## 证据标准

- 攻击路径(IAM 链/SSRF→元数据)
- 获取到的凭据或数据证明(脱敏)
- 横向可行性与影响范围

## 边界

- 不得删除或修改生产云资源
- 真实凭据不落盘不外传
- 法律敏感:本卡只写方法论与判定标准;示例仅限本方靶场内验证,不提供现成可执行武器(载荷/命令/利用代码)。
